اربط مساعد الذكاء الاصطناعي بشبكة RNTOR عبر Model Context Protocol (MCP)، واحصل على الإجابات والمعلومات فورًا بطرح أسئلتك بلغة طبيعية.

يربط RNTOR MCP بيانات RNTOR مباشرة بمساعدك — مثل Claude أو ChatGPT — باستخدام [Model Context Protocol (MCP)](https://modelcontextprotocol.io)، وهو معيار مفتوح لربط مساعدي الذكاء الاصطناعي بالأدوات والمنصات الأخرى. بعد الربط، يستطيع المساعد الوصول إلى بيانات شبكة RNTOR المصرح بها، فتسأله من داخل المحادثة وتحصل على الإجابة فورًا.

بدلًا من التنقل في لوحة المسؤول، اطرح السؤال بلغة طبيعية وسيعثر المساعد على ما تحتاج إليه. ويمكنه استخدام النتائج مع تطبيقاتك المتصلة الأخرى، مثل صياغة رسالة متابعة عبر البريد.

## ما الذي يمكنك فعله باستخدام RNTOR MCP؟

يمكن للمساعد البحث عن:

- **الشبكة والمواقع:** بيانات الشبكة وكل موقع.
- **الأعضاء والشركات:** معلومات العضوية والتواصل.
- **الخطط والاشتراكات:** اشتراكات الأعضاء والخطط المتاحة.
- **الموارد والحجوزات:** الموارد وتفاصيل الحجوزات.
- **الفواتير والعقود:** الفواتير والعقود وقوالبها.
- **المتجر والطلبات:** المنتجات والطلبات.
- **المزايا والطلبات:** المزايا وطلبات الاستفادة.
- **الأدلة:** أدلة المواقع ومحتواها.

## ربط RNTOR MCP

تحتاج إلى شبكة RNTOR نشطة فقط؛ لا توجد مفاتيح API أو استضافة أو إعداد تقني.

### الربط مع Claude

1. افتح **Settings → Connectors** في Claude وأضف موصلًا مخصصًا.
2. أدخل **RNTOR** اسمًا واستخدم العنوان:

```text
https://mcp.rntor.com/mcp
```

3. سجّل الدخول وامنح صلاحية الوصول إلى شبكة RNTOR.

[راجع دليل Claude الكامل](/ar/mcp-server/claude).

### الربط مع مساعد آخر

1. افتح إعدادات الموصلات في ChatGPT أو أي مساعد يدعم MCP.
2. أضف موصلًا مخصصًا بالعنوان:

```text
https://mcp.rntor.com/mcp
```

3. امنح صلاحية الوصول عند ظهور الطلب.

<Note>
  **التوافق مع الإصدارات السابقة:** يظل العنوان القديم `https://iwdewzswethsnvwvpind.supabase.co/functions/v1/mcp` صالحًا للاتصالات الحالية. استخدم `https://mcp.rntor.com/mcp` للاتصالات الجديدة.
</Note>

بعد الربط، اذكر ما تبحث عنه بلغة طبيعية، وسيعثر المساعد على المعلومات المناسبة.

أدوات RNTOR للقراءة فقط؛ تسترجع معلومات الشبكة وتلخصها ولا تغير أي بيانات. قد تتوفر إجراءات الكتابة مستقبلًا، ونواصل إضافة أنواع بيانات وقدرات جديدة.

## الأمان

### الوصول

- أنت من يمنح صلاحية الاتصال، ولا توجد مفاتيح API لإدارتها في تطبيق الذكاء الاصطناعي.
- يمكنك فصل RNTOR في أي وقت.
- يصل المساعد إلى الشبكة المصرح بها فقط، وفق دورك وصلاحياتك.

### البيانات

- الأدوات للقراءة فقط، فلا يمكن تغيير بيانات الحساب.
- يرى المساعد البيانات التي يستطيع حساب RNTOR الوصول إليها فقط.
- لا تُشارك البيانات خارج تطبيق الذكاء الاصطناعي الذي اخترته، وتخضع البيانات لشروطه وسياسة خصوصيته.

للأسئلة عن RNTOR MCP، تواصل عبر [support@rntor.com](mailto:support@rntor.com).

## الأسئلة الشائعة

### هل توجد حدود لعدد الأسئلة؟

صُمم RNTOR MCP للاستخدام الحواري المعتاد. عند ظهور `429` مؤقتًا، اطلب من الأداة تقليل العمليات المتوازية وترك فواصل بين الطلبات، ثم المحاولة بعد فترة قصيرة.
