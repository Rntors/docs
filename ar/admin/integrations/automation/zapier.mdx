يتيح لك تكامل Zapier ربط RNTOR بسهولة بتطبيقات أخرى وإنشاء مسارات عمل آلية مخصصة، بما يوفر الوقت ويقلل العمل اليدوي.

<Info>
  Zapier شركة مستقلة وغير تابعة لنا. لأي استفسارات عن حلولها أو خدماتها أو أسعارها، تواصل معها مباشرة؛ إذ لا نملك صلاحية تقديم معلومات أو دعم نيابةً عنها.
</Info>

## آلية عمل Zapier

المشغّلات والإجراءات هي أحداث داخل تطبيقاتك. يربط Zap بين مشغّل في تطبيق وإجراء في تطبيق آخر، فينفّذ Zapier المهام تلقائيًا عند وقوع حدث التشغيل.

توفر RNTOR مشغّلات وإجراءات يمكنك استخدامها عبر Zapier لربطها بتطبيقات أخرى. تعرّف على المزيد في [صفحة Zapier](https://rntor.com/integrations).

![تكامل Zapier](/images/integrations/automation-zapier-1.png)

### المشغّلات المدعومة

المشغّل هو الحدث الذي يبدأ مسار العمل الآلي.

| اسم المشغّل | الوصف |
| --- | --- |
| انتهاء الحجز | يعمل عند انتهاء حجز في أحد الموارد. |
| حذف عضو | يعمل عند حذف عضو من موقع. |
| طلب ميزة جديد | يعمل عند تقديم طلب جديد للحصول على ميزة في موقع. |
| حجز جديد | يعمل عند إنشاء حجز جديد في مورد. |
| شركة جديدة | يعمل عند إنشاء شركة جديدة في موقع. |
| تذكرة فعالية جديدة | يعمل عند شراء تذكرة فعالية جديدة في موقع. |
| فاتورة مُصدرة جديدة | يعمل عند إصدار فاتورة جديدة في موقع. |
| عضو جديد | يعمل عند دعوة عضو جديد للانضمام إلى موقع. |
| تسجيل جديد في الشبكة | يعمل عند تسجيل مستخدم جديد في شبكة. |
| طلب جديد | يعمل عند إنشاء طلب شراء جديد في موقع. |
| طلب انضمام جديد | يعمل عند تقديم طلب جديد للانضمام إلى موقع. |
| اشتراك جديد | يعمل عند إنشاء اشتراك جديد في موقع. |
| تذكرة دعم جديدة | يعمل عند إنشاء تذكرة دعم جديدة في موقع. |
| زيارة جديدة | يعمل عند إنشاء زيارة جديدة في موقع. |
| انتهاء الاشتراك | يعمل عند انتهاء اشتراك في موقع. |
| قرب انتهاء الاشتراك | يعمل عند اقتراب انتهاء اشتراك في موقع. |
| شراء اشتراك | يعمل عند شراء اشتراك في موقع. |

#### الإجراءات المدعومة

الإجراء هو المهمة التي ينفذها Zapier استجابةً للمشغّل.

| اسم الإجراء | الوصف |
| --- | --- |
| إنشاء حجز | ينشئ حجزًا جديدًا في مورد. |
| إنشاء شركة | ينشئ شركة جديدة في موقع. |
| إنشاء منشور في الخلاصة | ينشر منشورًا جديدًا. |
| إنشاء اشتراك لشركة | ينشئ اشتراكًا لشركة. |
| إنشاء اشتراك لمستخدم | ينشئ اشتراكًا لمستخدم. |
| إنشاء زيارة | ينشئ زيارة جديدة في موقع. |
| حذف حجز | يحذف حجزًا من مورد. |
| حذف عضو | يحذف عضوًا حسب المعرّف. |
| دعوة عضو | يدعو عضوًا جديدًا إلى موقع. |
| تحديث اشتراك | يغيّر تاريخ انتهاء الاشتراك. |

#### عمليات البحث المدعومة

تُستخدم عملية البحث للعثور على بيانات محددة في تطبيق قبل تنفيذ إجراء.

| اسم البحث | الوصف |
| --- | --- |
| العثور على شركة | يبحث عن شركة في موقع بالاسم أو المعرّف، ويمكنه إنشاء شركة إذا لم يجدها. |
| العثور على عضو | يبحث عن عضو في موقع بالاسم أو المعرّف، ويمكنه إنشاء عضو إذا لم يجده. |
| العثور على حجز | يبحث عن حجز، ويمكنه إنشاء حجز إذا لم يجده. |

## إعداد أتمتة

لربط RNTOR بتطبيق آخر:

1. سجّل الدخول إلى [Zapier](https://zapier.com/app/login) وابدأ [إنشاء Zap](https://help.zapier.com/hc/en-us/articles/22234847450893-Zap-workflows-quick-start-guide).
2. عند اختيار RNTOR كمشغّل أو إجراء، اربط حسابك بتسجيل الدخول عبر البريد الإلكتروني الخاص بحساب [المسؤول](/ar/admin/administration/administrators/administrators) في RNTOR.
3. اضبط الأتمتة المطلوبة باختيار المشغّلات والإجراءات المناسبة.
4. اختبر Zap ثم انشره.

### حالات استخدام شائعة

- **التكامل مع CRM:** ادعُ جهات الاتصال تلقائيًا إلى بوابة الأعضاء وتطبيق الجوال، أو أنشئ سجلات CRM جديدة عند إضافة أعضاء إلى RNTOR. [مثال HubSpot](https://zapier.com/apps/hubspot/integrations)
- **التكامل المحاسبي:** زامن الفواتير والمدفوعات المالية للخدمات، وحافظ على اتساق سجلات العملاء بين الأنظمة.

<Tip>
  استكشف [طرقًا إضافية](/ar/admin/billing/invoices/accounting) لربط RNTOR بأدوات المحاسبة.
</Tip>

- **الإشعارات والاتصالات الخارجية:** أخطر مزودي المزايا أو المنتجات، وتتبّع تسجيل المستخدمين عبر إشعارات آلية باستخدام Gmail وOutlook وSlack وغيرها. [مثال Gmail](https://zapier.com/apps/gmail/integrations)

**الأسئلة الشائعة**

</Accordion>
