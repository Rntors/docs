يتيح Zapier ربط RNTOR بتطبيقات أخرى وإنشاء مسارات عمل مخصصة توفر الوقت وتقلل العمل اليدوي.

<Info>
  Zapier شركة مستقلة وغير تابعة لـRNTOR. للاستفسار عن خدماتها أو أسعارها، تواصل معها مباشرة.
</Info>

## آلية عمل Zapier

يربط Zap بين مُشغّل في تطبيق وإجراء في تطبيق آخر، وينفّذ المهمة تلقائيًا عند وقوع الحدث. يوفر RNTOR مُشغّلات وإجراءات وعمليات بحث. [استكشف التكاملات](https://rntor.com/integrations).

![آلية Zapier](/images/integrations/automation-zapier-1.png)

### المُشغّلات المدعومة

| المُشغّل | الوصف |
| --- | --- |
| انتهاء حجز | عند انتهاء حجز مورد |
| حذف عضو | عند حذف عضو من موقع |
| طلب ميزة جديد | عند تقديم طلب ميزة |
| حجز جديد | عند إنشاء حجز مورد |
| شركة جديدة | عند إنشاء شركة |
| تذكرة فعالية جديدة | عند شراء تذكرة |
| فاتورة صادرة جديدة | عند إصدار فاتورة |
| عضو جديد | عند دعوة عضو |
| تسجيل جديد في الشبكة | عند تسجيل مستخدم |
| طلب متجر جديد | عند إنشاء طلب |
| طلب انضمام جديد | عند تقديم طلب |
| اشتراك جديد | عند إنشاء اشتراك |
| تذكرة دعم جديدة | عند إنشاء تذكرة |
| زيارة جديدة | عند إنشاء زيارة |
| انتهاء اشتراك | عند انتهاء اشتراك |
| قرب انتهاء اشتراك | عند اقتراب نهايته |
| شراء اشتراك | عند شراء اشتراك |

### الإجراءات المدعومة

| الإجراء | الوصف |
| --- | --- |
| إنشاء حجز أو شركة أو منشور أو زيارة | ينشئ السجل المطلوب |
| إنشاء اشتراك لشركة أو مستخدم | ينشئ الاشتراك |
| حذف حجز أو عضو | يحذف السجل |
| دعوة عضو | يدعو عضوًا إلى الموقع |
| تحديث اشتراك | يغيّر تاريخ نهاية الاشتراك |

### عمليات البحث المدعومة

| البحث | الوصف |
| --- | --- |
| العثور على شركة | بالاسم أو المعرّف، ويمكن إنشاؤها إن لم توجد |
| العثور على عضو | بالاسم أو المعرّف، ويمكن دعوته إن لم يوجد |
| العثور على حجز | ويمكن إنشاؤه إن لم يوجد |

## إعداد أتمتة

1. سجّل الدخول إلى [Zapier](https://zapier.com/app/login) وابدأ [إنشاء Zap](https://help.zapier.com/hc/en-us/articles/22234847450893-Zap-workflows-quick-start-guide).
2. عند اختيار RNTOR كمُشغّل أو إجراء، اربط الحساب ببريد [مسؤول RNTOR](/ar/admin/administration/administrators/administrators).
3. اختر المُشغّلات والإجراءات واضبط الحقول.
4. اختبر Zap وانشره.

### أمثلة شائعة

- **CRM:** دعوة جهات الاتصال تلقائيًا أو إنشاء سجل عند إضافة عضو. [مثال HubSpot](https://zapier.com/apps/hubspot/integrations)
- **المحاسبة:** مزامنة الفواتير والمدفوعات وسجلات العملاء. [طرق ربط المحاسبة](/ar/admin/billing/invoices/accounting)
- **الإشعارات:** إخطار مزودي المزايا أو المنتجات وتتبع التسجيلات عبر Gmail أو Outlook أو Slack. [مثال Gmail](https://zapier.com/apps/gmail/integrations)
