تدعم RNTOR خمسة تكاملات رئيسية للتحكم في الوصول: Kisi وBrivo وSalto KS وAvigilon Alta وTapkey. كما يطوّر بعض المزوّدين تكاملاتهم الخاصة مع RNTOR ويحافظون عليها، مثل Luckey.

عند اختيار المزوّد، راعِ تجربة الأعضاء وآلية الإدارة اليومية.

## مقارنة التكاملات

| **التكامل** | **فتح الأبواب عبر RNTOR** | **منح الوصول بناءً على** | **دعوة بريدية لتثبيت تطبيق النظام** | **التطوير والصيانة** |
| --- | --- | --- | --- | --- |
| [Kisi](/ar/admin/integrations/access-control/kisi) | ✓ | الاشتراكات والحجوزات | غير مطلوبة | RNTOR |
| [Brivo](/ar/admin/integrations/access-control/brivo) | ✓ | الاشتراكات والحجوزات | غير مطلوبة | RNTOR |
| [Salto KS](/ar/admin/integrations/access-control/salto-ks) | ✓ | الاشتراكات والحجوزات | غير مطلوبة | RNTOR |
| [Avigilon Alta](/ar/admin/integrations/access-control/avigilon-alta) | _X_ | الاشتراكات والحجوزات | نعم | RNTOR |
| [Tapkey](/ar/admin/integrations/access-control/tapkey) | _X_ | الاشتراكات والحجوزات | لا؛ ينزّل المستخدم التطبيق بنفسه | RNTOR |
| [Luckey](/ar/admin/integrations/access-control/luckey) | _X_ | الاشتراكات والانتماء إلى شركة | نعم | Luckey |

## الفرق الرئيسي

تُمنح الصلاحية وتُسحب تلقائيًا بالطريقة نفسها في جميع التكاملات التي طورتها RNTOR:

- عند امتلاك المستخدم حجزًا أو اشتراكًا نشطًا، تتم مزامنته تلقائيًا مع نظام التحكم وإضافته إلى مجموعة الوصول المناسبة.
- عند انتهاء الحجز أو الاشتراك، يُزال تلقائيًا من المجموعة.

الفرق الأساسي هو ما إذا كان المستخدم يفتح الباب من تطبيق RNTOR أو بوابتها، أم يستخدم وسيلة خارجية.

### فتح الأبواب داخل RNTOR

**مدعوم في: Kisi وBrivo وSalto KS**

1. يفتح المستخدم الأبواب من تطبيق الأعضاء أو بوابة الويب:
   - Kisi وBrivo: من صفحة **الوصول**.
   - Salto KS: عبر زر **فتح**.
2. لا يحتاج إلى تطبيقات إضافية أو دعوات.

### فتح الأبواب خارج RNTOR

**مدعوم في: Avigilon Alta وTapkey وLuckey**

1. يحصل المستخدم على حجز أو اشتراك عبر RNTOR.
2. تزامنه RNTOR وتمنحه الوصول تلقائيًا.
3. يفتح الباب بالوسائل التي يوفرها المزوّد، مثل تطبيقه الأصلي أو Apple Wallet أو البطاقات أو وحدات المفاتيح.

الطريقة الأكثر شيوعًا هي تطبيق المزوّد. وعند المزامنة الأولى، يرسل Avigilon Alta وLuckey دعوة بريدية تلقائية لتثبيت التطبيق.
