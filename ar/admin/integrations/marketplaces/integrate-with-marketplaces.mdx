يمكنك ربط RNTOR بمنصات الأسواق عبر تقويم Google أو API لمزامنة حجوزات الغرف والمقاعد الخارجية تلقائيًا.

<Info>
  منصة السوق التي تختارها شركة مستقلة وغير تابعة لـRNTOR. للاستفسار عن خدماتها أو أسعارها، تواصل معها مباشرة.
</Info>

## التكامل عبر تقويم Google

<Info>
  تأكد أولًا أن السوق يدعم التكامل مع تقويم Google.
</Info>

1. اربط [تقويم Google](/ar/admin/integrations/bookings/google-calendar) وأعدّه للموارد المطلوبة.
2. امنح بريد السوق صلاحية تعديل الأحداث في التقويمات، وفق إرشادات المنصة.
3. أرسل **معرّف التقويم** و**الرابط العام** إلى دعم المنصة واطلب تفعيل التكامل.

### آلية العمل

- يُنشأ الحجز الخارجي في Google ثم يُزامن إلى RNTOR لحظيًا.
- يختلف التحقق من التوفر والمدى الزمني للحجوزات حسب المنصة؛ راجع وثائقها.
- في المقاعد والمكاتب والمعدات والمواقف، يحجز كل حدث مقعدًا واحدًا في المورد المقابل.

## التكامل عبر API

للتكاملات المخصصة، يوفر RNTOR [واجهة API](/ar/admin/administration/api-and-webhooks) للربط المباشر وتكييف سير العمل.
