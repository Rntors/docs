  <Tab title="الغرف">
    أضف غرف Skype وكبائن الهاتف وغرف الاجتماعات وقاعات المؤتمرات أو مساحات الفعاليات إلى صفحة **الغرف**. وبذلك يحصل العملاء على تقويم ملائم للتحقق من التوافر وإجراء الحجوزات.

    ## تفعيل الغرف

    لبدء استخدام وحدة **الغرف**:

    1. من اللوحة الجانبية، اضغط قائمة **(...)** بجوار اسم موقعك.
    2. انتقل إلى **إعدادات الموقع** \> **الموارد** \> **الغرف** وفعّل مفتاح **الغرف**.
    3. **اسم الصفحة** — اختر الاسم الأنسب.
    4. **الحجز مقدمًا** — حدد المدة التي يمكن للمستخدمين الحجز قبلها.
       <Info>
         يسري حد **الحجز مقدمًا** على الحجوزات المتكررة أيضًا. يجب أن يقع كل تكرار ضمن نافذة الحجز المسبق؛ فإذا تجاوزتها السلسلة، تعرض بوابة الأعضاء للمستخدم آخر تاريخ يمكنه الحجز حتى بلوغه، ويلزمه تعديل إعداد **إنهاء التكرار**. اختر **غير محدود** للسماح بالحجز من دون حد زمني وإزالة هذا القيد.
       </Info>
    5. **الحجز مجانًا** — إذا كانت لديك غرف مجانية، فحدد عدد الحجوزات المجانية المجدولة التي يمكن للمستخدم الاحتفاظ بها في الوقت نفسه:
       - حجز نشط واحد
       - حجزان نشطان
       - ثلاثة حجوزات نشطة
       - غير محدود

    لا يسري إعداد **الحجز مجانًا** إلا على الغرف المجانية بالكامل والحجوزات التي ينشئها مستخدمون غير مسؤولين. وبعد انتهاء الحجوزات السابقة المجدولة، يستطيع المستخدمون إنشاء حجوزات مجانية جديدة. [تحسين استخدام الغرف](/ar/guides/revenue-and-space-optimization/optimize-room-usage)

    ![إعدادات الغرف في إدارة الموارد](/images/resource-management-rooms-1.png)

    ## إضافة الغرف

    1. انتقل إلى صفحة **الموارد** \> **الغرف**.
    2. اضغط **إضافة غرفة** أعلى اليسار.

    ![إضافة غرفة](/images/resource-management-rooms-2.png)

    3. أدخل تفاصيل الغرفة.

    | **اسم القسم** | **المعنى** |
    | :-- | :-- |
    | **صورة الغرفة** | بنسبة عرض إلى ارتفاع 2:1. |
    | **النوع** | <ul><li>غرفة</li><li>قاعة مؤتمرات</li><li>مساحة فعاليات</li><li>غرفة اجتماعات</li><li>كابينة هاتف</li><li>استوديو</li></ul> |
    | **الاسم** | اسم الغرفة و/أو رقمها. |
    | **السعة المقعدية** | عدد الأشخاص الذين تستوعبهم الغرفة. |
    | **الوصف** | أضف أي معلومات مهمة يحتاج العملاء إلى معرفتها. |
    | **المال** | السعر النقدي للحجوزات بالساعة أو اليوم بعملة موقعك. [<u>إعداد تسعير الموارد</u>](/ar/admin/resource-management/resources/set-up-pricing) |
    | **الرصيد** | سعر الحجز بالساعة أو اليوم من الرصيد. |
    | **التسعير الديناميكي (تجريبي)** | يضبط سعر حجز الغرفة تلقائيًا وفق الطلب، ضمن النطاق الذي تحدده. [<u>إعداد التسعير الديناميكي للمورد</u>](/ar/admin/resource-management/resources/dynamic-pricing) |
    | **الخطط** | إذا كنت تقدم إيجارات طويلة الأجل لهذه الغرفة، أسبوعية أو شهرية مثلًا، ففعّل **الخطط** وأضف الشرائح. <ul><li>عطّل المفتاح إذا كانت الغرفة متاحة للحجز بالساعة أو اليوم فقط.</li></ul> [<u>إعداد تسعير الموارد</u>](/ar/admin/resource-management/resources/set-up-pricing) |
    | **الفاصل الزمني للتوافر** | تواتر الأوقات المتاحة لحجز الغرفة، ويظهر كخطوة زمنية أثناء الحجز. |
    | **الحد الأدنى والأقصى للمدة** | حدود مدة الحجوزات بالساعة أو اليوم، وتسري على جميع المستخدمين باستثناء المسؤولين. <ul><li>لوضع حدود مختلفة لغير الأعضاء، فعّل **المدة العامة** وحدد الحدين اللذين يسريان عليهم.</li></ul> |
    | **وقت التجهيز** | مدة فاصلة تُحجز بين الحجوزات. |
    | **سياسة إعادة الجدولة** | حدد هل يمكن للمستخدمين إعادة جدولة حجوزات هذه الغرفة أو إلغاؤها واسترداد المبلغ تلقائيًا. [<u>فهم المبالغ المستردة</u>](/ar/admin/billing/payments/refunds) |
    | **الجدول المخصص** | حدد [<u>ساعات عمل مخصصة</u>](/ar/admin/location/schedule#تهيئة-جدول-مخصص-لمورد) لهذه الغرفة بصورة مستقلة عن الجدول العام للموقع. |
    | **رسالة التأكيد الإلكترونية** | لإرسال [<u>رسالة مخصصة لتأكيد الحجز</u>](/ar/admin/general/customize-emails#تأكيدات-الحجز)، اختر المستخدمين الذين يتلقونها عند الحجز وأدخل نص الرسالة. |
    | **إمكانية الرؤية** | حدد مجموعات المستخدمين التي يمكنها رؤية الغرفة. |
    | **الحجز** | حدد مجموعات المستخدمين التي يمكنها حجز الغرفة فورًا، بينما يقدم الآخرون طلب حجز. <ul><li>[<u>حجز غرفة</u>](/ar/member/bookings/book-a-room)</li><li>[<u>تهيئة صلاحيات حجز الغرف</u>](/ar/admin/resource-management/resources/applications-for-bookings)</li></ul> |
    | **الغرفة الأصلية** | إذا كانت الغرفة تتداخل مع مساحة أكبر أو ترتبط بها—كأن تكون نصف غرفة قابلة للتقسيم أو داخل قاعة فعاليات—فاختر المساحة الأكبر **غرفة أصلية**. عند حجز الغرفة الأصلية تُحجب هذه الغرفة تلقائيًا، والعكس صحيح. |
    | **الحماية من الحجوزات غير المستخدمة**\* | تزيل الحجوزات غير المستخدمة تلقائيًا من تقويم الغرفة إذا لم يسجّل أحد وصوله. تتوفر فقط مع [<u>شاشة الغرف</u>](/ar/admin/resource-management/room-display/set-up-room-display). _\*لا يظهر هذا الخيار إلا إذا كانت الغرفة مجانية بالكامل._ |
    | **الوصول** | حدد مجموعة التحكم بالوصول التي تتم مزامنة المستخدمين معها عند حجز الغرفة. <br />يظهر إذا كان [<u>تكامل نظام التحكم بالوصول</u>](/ar/admin/integrations/access-control/set-up-access-control) متصلًا بالموقع. |
    | **مزامنة التقويم** | زامن حجوزات هذه الغرفة مع [<u>تقويم Google</u>](/ar/admin/integrations/bookings/google-calendar) المحدد. |

    <Tip>
      إذا كنت تؤجر معدات للاجتماعات أو الفعاليات أو العروض، مثل الكراسي والشاشات والسبورات، [فأدرجها في صفحة **المعدات**](#المعدات). ويمكنك إضافة روابطها إلى أوصاف الغرف لتعريف العملاء بالخيارات المتاحة وتشجيع المبيعات الإضافية إلى جانب الحجوزات.
    </Tip>

    <Tip>
      تعرّف على كيفية [حجز المستخدمين لغرفة](/ar/member/bookings/book-a-room) و[اشتراكهم لاستئجارها](/ar/admin/resource-management/resources/rental-applications-or-immediate-sign-ups).
    </Tip>

    ## تعديل غرفة

    لتحديث إعدادات غرفة:

    1. انتقل إلى **الموارد** \> **الغرف**.
    2. مرّر المؤشر فوق الغرفة المطلوبة، واضغط قائمة **(...)** بجوارها، ثم **تعديل**.

    ![تعديل مورد](/images/resource-management-edit-a-resource-1.png)

    3. عدّل إعدادات الغرفة حسب الحاجة.
    4. اضغط **حفظ** أعلى اليسار.

    <Info>
      لا تسري تغييرات الأسعار في أي [شريحة سعرية](/ar/admin/resource-management/resources/set-up-pricing) أو [سياسة إعادة الجدولة](/ar/admin/billing/payments/refunds) إلا على الحجوزات المستقبلية التي تُنشأ بعد التحديث.
    </Info>

    ## حذف غرفة

    لحذف غرفة نهائيًا من RNTOR:

    1. انتقل إلى **الموارد** \> **الغرف**.
    2. مرّر المؤشر فوق الغرفة المطلوبة، واضغط قائمة **(...)** بجوارها، ثم اختر **حذف** وأكد اختيارك.

    ![حذف مورد](/images/resource-management-delete-a-resource-1.png)

    <Warning>
      لا يمكن التراجع عن حذف الغرفة. تُحذف جميع الحجوزات المرتبطة بها نهائيًا من دون استرداد، ولا يمكن استعادتها، كما لن تعود تحليلات حجوزات الغرفة المحذوفة متاحة.
    </Warning>

    **الأسئلة الشائعة**

    <Accordion title="ما الذي ينبغي إضافته إلى الغرف؟">
      صفحة **الغرف** مخصصة لغرف الاجتماعات والمؤتمرات وكبائن الهاتف وغرف Skype. وإذا كانت لديك استوديوهات تصوير أو بودكاست، فأدرجها في صفحة **الغرف** أيضًا.
    </Accordion>

    <Accordion title="كيف يمكنني إيقاف حجز جميع الغرف لعدة أيام؟">
      إذا كنت ستقيم فعالية في المساحة أو تقترب عطلة، فضع علامة «مغلق» على التواريخ المقابلة في جدول موقعك لتصبح جميع الموارد غير متاحة للعملاء في تلك الأيام.

      ولإيقاف الغرف فقط مع إبقاء الموارد الأخرى متاحة، ضع علامة «مغلق» على التواريخ في الجدول المخصص لكل غرفة. [تهيئة الجدول](/ar/admin/location/schedule)
    </Accordion>

    <Accordion title="كيف أحدد جدول حجز الغرف للأعضاء وغير الأعضاء؟">
      يمكنك تهيئة جدول موحّد للموقع يسري على جميع الموارد، أو إعداد جدول مخصص لغرفة بعينها إذا كانت تحتاج إلى أوقات توافر مختلفة. [تهيئة الجدول](/ar/admin/location/schedule)
    </Accordion>

    <Accordion title="لماذا لا يستطيع أحد العملاء رؤية غرفة معينة؟">
      قد لا يرى العميل الغرفة للأسباب التالية:

      1. دور العميل لا يطابق متطلبات رؤية الغرفة. فإذا كانت مرئية لـ**أعضاء الموقع** فقط وكان العميل غير عضو، فلن تظهر له. راجع كلًا من إعدادات [رؤية الغرفة](/ar/admin/location/visibility) و[دور العميل](/ar/admin/customer-management/users/user-roles).
      2. قد تكون الغرفة معيّنة لعميل محدد، فلا تكون مرئية وقابلة للحجز إلا له. راجع صفحة **الغرف** لمعرفة ما إذا كان اسم عضو أو شركة يظهر بجوارها. ولإزالة التعيين، عدّل اشتراك ذلك العميل.
      3. ربما سجّل العميل الدخول ببريد إلكتروني مختلف. إذا كان عضوًا وينبغي أن يرى الغرفة، فتحقق من البريد المرتبط بملفه في صفحة **العملاء**.
    </Accordion>

  <Tab title="المكاتب">
    أضف جميع محطات العمل وأدرها—مثل المكاتب المرنة أو المخصصة أو محطات العمل—من صفحة **المكاتب**.

    تتيح لك المكاتب:

    - تنظيم محطات العمل ومتابعة الإشغال لحظيًا.
    - تقديم حجوزات قصيرة الأجل بالساعة أو اليوم، وإيجارات طويلة الأجل عبر الاشتراكات.

    ## تهيئة الإعدادات العامة للمكاتب

    1. من اللوحة الجانبية، اضغط **(...)** بجوار اسم موقعك.
    2. انتقل إلى **إعدادات الموقع** \> **الموارد** \> **المكاتب**.
    3. تأكد من تفعيل مفتاح **المكاتب**.
    4. **اسم الصفحة** — اختر الاسم الأنسب.
    5. **الحجز مقدمًا** — حدد المدة التي يمكن للمستخدمين حجز المكاتب قبلها.
    6. **تصاريح اليوم** — اسمح للأعضاء بحجز المكاتب المرنة باستخدام [تصاريح اليوم](/ar/admin/billing/credits-and-day-passes/day-passes).
    7. **حد الاستخدام** — قيّد عدد تصاريح اليوم التي يمكن للعضو استخدامها يوميًا.

    ![تهيئة الإعدادات العامة للمكاتب](/images/resource-management-desks-configure-general-desk-settings.png)

    ## إعداد المكاتب

    1. انتقل إلى **الموارد** \> **المكاتب**.
    2. اضغط **إضافة مكتب** أعلى اليسار.

    ![إضافة مكتب](/images/resource-management-desks-2.png)

    - **صورة المكتب** — بنسبة عرض إلى ارتفاع 2:1.
    - **النوع**
      - **مكتب مرن** — مشترك وغير مخصص لعميل بعينه، ويمكن حجزه حسب التوافر.
      - **مكتب مخصص** — يمكن حجزه لعميل محدد.
      - **محطة عمل** — مساحة عمل مزودة عادةً بأدوات أو أثاث يناسب مهمة معينة.
    - **الاسم** — اختر طريقة التسمية:
      - **المناطق**، مثل **المساحة المفتوحة** أو **منطقة الاستراحة** أو **المساحة المفتوحة – الطابق الأول** و**المساحة المفتوحة – الطابق الثاني**، مع تحديد إجمالي السعة لمتابعة الإشغال حسب المنطقة.
      - **المكاتب المرقمة**، مثل **المكتب المخصص 1**، ليتمكن المستخدمون من حجز مكتب بعينه أو الاشتراك فيه. [خيارات إعداد المكاتب](#خيارات-إعداد-المكاتب)
    - **السعة المقعدية** — عدد المقاعد التي يتيحها المكتب أو المنطقة.
    - **الوصف** — المعلومات التي يحتاج العملاء إلى معرفتها.
    - **المال** — السعر النقدي للحجوزات بالساعة أو اليوم.
      - عطّله إذا كان المكتب متاحًا للإيجار طويل الأجل فقط.
    - **الرصيد** — سعر الحجز بالساعة أو اليوم من الرصيد.
      - عطّله إذا كان المكتب متاحًا للإيجار طويل الأجل فقط.
    - **تصاريح اليوم** — اسمح للأعضاء بحجز المكتب باستخدام [تصاريح اليوم](/ar/admin/billing/credits-and-day-passes/day-passes). _يظهر فقط لنوع **مكتب مرن**._
    - **التسعير الديناميكي** — يضبط سعر الحجز تلقائيًا وفق [الطلب](/ar/admin/resource-management/resources/dynamic-pricing).
    - **الخطط** — فعّلها إذا كنت تقدم إيجارات طويلة الأجل للمكتب، أسبوعية أو شهرية مثلًا، ثم [أضف الشرائح](/ar/admin/resource-management/resources/set-up-pricing).
      - عطّلها إذا كان المكتب متاحًا للحجز بالساعة أو اليوم فقط.
    - **الفاصل الزمني للتوافر** — الخطوة الزمنية للحجز.
    - **الحد الأدنى والأقصى للمدة** — حدود مدة الحجز، وتسري على جميع المستخدمين باستثناء المسؤولين.
    - **المدة العامة** — فعّلها لوضع حدود مختلفة لمدة الحجز لغير الأعضاء.
    - **سياسة إعادة الجدولة** — حدد هل يمكن للمستخدمين إعادة جدولة الحجوزات أو إلغاؤها واسترداد المبلغ تلقائيًا. [فهم المبالغ المستردة](/ar/admin/billing/payments/refunds)
    - **الجدول المخصص** — [ساعات عمل مخصصة](/ar/admin/location/schedule) لهذا المكتب.
    - **رسالة التأكيد الإلكترونية** — أرسل [رسالة مخصصة لتأكيد الحجز](/ar/admin/general/customize-emails)، واختر متلقيها وأدخل نصها.
    - **إمكانية الرؤية** — حدد مجموعات المستخدمين التي يمكنها رؤية المكتب.
    - **الحجز** — حدد المجموعات التي يمكنها [حجز المكتب](/ar/member/bookings/book-a-desk) فورًا، بينما [يقدم الآخرون طلب حجز](/ar/admin/resource-management/resources/applications-for-bookings).
    - **الغرفة الأصلية** — إذا كان المكتب يتداخل مع مساحة أكبر أو يرتبط بها، كوجوده داخل قاعة فعاليات، فاختر المساحة الأكبر ل[ربطهما](/ar/admin/resource-management/resources/overlapping-resources).
    - **الوصول** — مجموعة التحكم بالوصول للمستخدمين الذين يحجزون المكتب أو يستأجرونه. _يظهر إذا كان [تكامل نظام التحكم بالوصول](/ar/admin/integrations/access-control/set-up-access-control) متصلًا._
    - **مزامنة التقويم** — زامن حجوزات المكتب مع [تقويم Google](/ar/admin/integrations/bookings/google-calendar).

    ### خيارات إعداد المكاتب

    **حسب المناطق** — إذا أردت أن يحجز المستخدمون مكتبًا من دون اختيار مقعد محدد:

    - أنشئ كل منطقة كمكتب.
    - حدد السعة المقعدية لكل منطقة.
    - يختار المستخدمون المنطقة ويحجزون مقعدًا واحدًا أو أكثر.

    إذا كنت تستخدم مخططات الطوابق، فستظهر المكاتب كما يلي:

    ![إعداد المكاتب حسب المناطق](/images/resource-management-desks-3.png)

    **كمكاتب منفردة** — إذا أردت أن يختار المستخدمون مقعدًا بعينه:

    - أنشئ كل مكتب كمورد مستقل.
    - اضبط السعة المقعدية على 1.
    - يختار المستخدمون المقعد الذي يفضلونه ويحجزونه.

    إذا كانت لديك مخططات طوابق، فستظهر المكاتب وفقًا لذلك:

    ![إعداد المكاتب كموارد منفردة](/images/resource-management-desks-4.png)

    <Tip>
      يمكنك [إنشاء المكاتب بالجملة](/ar/admin/noor-ai/bulk-create-resources-products-events-and-benefits) بمساعدة Noor AI.
    </Tip>

    ## الخطوة التالية

    بعد إعداد المكاتب:

    - يستطيع العملاء العثور عليها في صفحة **المكاتب** و[حجزها](/ar/member/bookings/book-a-desk) أو [الاشتراك لاستئجارها](/ar/admin/resource-management/resources/rental-applications-or-immediate-sign-ups).
    - يتلقى المسؤولون [إشعارات](/ar/admin/administration/your-account/notifications/set-up-notifications) بالحجوزات والاشتراكات الجديدة في صفحة **الإشعارات**.
    - تعرض صفحة **المكاتب** نظرة لحظية على إشغال المكاتب في مساحتك.

    ![نظرة عامة على إشغال المكاتب](/images/resource-management-desks-5.png)

    - بالإضافة إلى ذلك:
      - تابع الحجوزات حسب اليوم من علامة تبويب **المكاتب** \> **الحجوزات**.
      - اعرض جميع الحجوزات حسب الفترة أو العميل من **الموارد** \> **الحجوزات**.
      - تابع جميع إيجارات المكاتب طويلة الأجل على مخطط **الموارد** \> [**التعيينات**](/ar/admin/analytics-reports/track-occupancy) [الزمني](/ar/admin/analytics-reports/track-occupancy).

    ## تعديل مكتب

    لتحديث إعدادات مكتب:

    1. انتقل إلى **الموارد** \> **المكاتب**.
    2. مرّر المؤشر فوق المكتب المطلوب، واضغط قائمة **(...)** بجواره، ثم **تعديل**.
    3. عدّل الإعدادات حسب الحاجة.
    4. اضغط **حفظ** أعلى اليسار.

    <Info>
      لا تسري تغييرات الأسعار في أي [شريحة سعرية](/ar/admin/resource-management/resources/set-up-pricing) أو [سياسة إعادة الجدولة](/ar/admin/billing/payments/refunds) إلا على الحجوزات المستقبلية التي تُنشأ بعد التحديث.
    </Info>

    ## حذف مكتب

    لحذف مكتب نهائيًا من RNTOR:

    1. انتقل إلى **الموارد** \> **المكاتب**.
    2. مرّر المؤشر فوق المكتب المطلوب، واضغط قائمة **(...)** بجواره، ثم اختر **حذف** وأكد اختيارك.

    <Warning>
      لا يمكن التراجع عن حذف المكتب. تُحذف جميع الحجوزات المرتبطة به نهائيًا من دون استرداد ولا يمكن استعادتها، كما لن تعود تحليلات حجوزاته متاحة.
    </Warning>

    **الأسئلة الشائعة**

    <Accordion title="كيف يمكنني إيقاف حجز المكاتب لعدة أيام؟">
      لإيقاف مكاتب محددة فقط مع إبقاء الموارد الأخرى متاحة، ضع علامة «مغلق» على التواريخ المقابلة في إعداد **الجدول المخصص** لكل مكتب.

      وإذا كنت ستقيم فعالية في المساحة أو تقترب عطلة، فضع علامة «مغلق» على التواريخ في [جدول الموقع](/ar/admin/location/schedule) العام لتصبح جميع الموارد غير متاحة للحجز في تلك الأيام.
    </Accordion>

    <Accordion title="كيف أحدد جدول حجز المكاتب للأعضاء وغير الأعضاء؟">
      يمكنك تهيئة جدولي **عام** و**افتراضي** ضمن [جدول الموقع](/ar/admin/location/schedule) العام، أو إعداد جدول مخصص لمكتب بعينه إذا كان يحتاج إلى أوقات توافر مختلفة.
    </Accordion>

    <Accordion title="كيف أهيئ مساحة عمل للحجز ليوم واحد بصورة صحيحة؟">
      1. انتقل إلى صفحة **الموارد \> المكاتب** وابدأ إضافة مكتب.
      2. اضبط الحد الأدنى والأقصى للمدة على **يوم واحد**، وحدد السعر اليومي.
      3. هيئ الخصائص الأخرى.

      بعد ذلك، يستطيع عملاؤك حجز المكتب بسعر يومي من صفحة **المكاتب**.
    </Accordion>

    | اسم القسم | المعنى |
    | :-- | :-- |
    | **صورة المكتب** | بنسبة عرض إلى ارتفاع 2:1. |

    | **الخطط** | <ul><li>عطّل هذا الخيار إذا كنت لا تريد نشر أسعار المكتب. سيظهر للعملاء زر **تواصل معنا** ليتمكنوا من الاتصال بك.</li></ul> |
    | **الجدول المخصص** | حدد [<u>ساعات عمل مخصصة</u>](/ar/admin/location/schedule#تهيئة-جدول-مخصص-لمورد) للمكتب بصورة مستقلة عن الجدول العام للموقع. |
    | **إمكانية الرؤية** | حدد مجموعات المستخدمين التي يمكنها رؤية المكتب. |
    | **الوصول** | حدد مجموعة التحكم بالوصول للعملاء المشتركين في المكتب. <br />يظهر إذا كان [<u>تكامل نظام التحكم بالوصول</u>](/ar/admin/integrations/access-control/set-up-access-control) متصلًا بالموقع. |
    | **مزامنة التقويم** | زامن حجوزات المكتب مع [<u>تقويم Google</u>](/ar/admin/integrations/bookings/google-calendar) المحدد. |

    4. اضغط **إنشاء**. تصبح المكاتب ظاهرة في صفحة **المكاتب الخاصة** في بوابة الويب للأعضاء وتطبيق الجوال.

    ![ظهور المكاتب الخاصة للعملاء](/images/resource-management-offices-3.png)

    <Tip>
      يمكنك [إنشاء المكاتب الخاصة بالجملة](/ar/admin/noor-ai/bulk-create-resources-products-events-and-benefits) بمساعدة Noor AI.
    </Tip>

    | **سياسة إعادة الجدولة** | حدد هل يمكن للمستخدمين إعادة جدولة الحجز أو إلغاؤه واسترداد المبلغ تلقائيًا. [<u>فهم المبالغ المستردة</u>](/ar/admin/billing/payments/refunds) |
    | **الجدول المخصص** | حدد [<u>ساعات عمل مخصصة</u>](/ar/admin/location/schedule#تهيئة-جدول-مخصص-لمورد) للمعدات. |
    | **رسالة التأكيد الإلكترونية** | لإرسال [<u>رسالة مخصصة لتأكيد الحجز</u>](/ar/admin/general/customize-emails#تأكيدات-الحجز)، اختر متلقيها وأدخل نصها. |
    | **إمكانية الرؤية** | حدد مجموعات المستخدمين التي يمكنها رؤية المعدات. |
    | **الحجز** | حدد المجموعات التي يمكنها حجز المعدات فورًا، بينما يقدم الآخرون طلبًا. <ul><li>[<u>حجز معدات</u>](/ar/member/bookings/book-equipment)</li><li>[<u>تهيئة صلاحيات حجز المعدات</u>](/ar/admin/resource-management/resources/applications-for-bookings)</li></ul> |
    | **الوصول** | حدد مجموعة التحكم بالوصول التي تتم مزامنة المستخدمين معها عند الحجز. يظهر إذا كان [<u>تكامل نظام التحكم بالوصول</u>](/ar/admin/integrations/access-control/set-up-access-control) متصلًا. |
    | **مزامنة التقويم** | زامن حجوزات المعدات مع [<u>تقويم Google</u>](/ar/admin/integrations/bookings/google-calendar) المحدد. |

    <Tip>
      تعرّف على كيفية [حجز المستخدمين للمعدات](/ar/member/bookings/book-equipment) و[اشتراكهم لاستئجارها](/ar/admin/resource-management/resources/rental-applications-or-immediate-sign-ups).
    </Tip>

    ## تعديل معدات

    1. انتقل إلى **الموارد** \> **المعدات**.
    2. مرّر المؤشر فوق العنصر المطلوب، واضغط قائمة **(...)** بجواره، ثم **تعديل**.
    3. عدّل الإعدادات حسب الحاجة.
    4. اضغط **حفظ** أعلى اليسار.

    <Info>
      لا تسري تغييرات الأسعار في أي [شريحة سعرية](/ar/admin/resource-management/resources/set-up-pricing) أو [سياسة إعادة الجدولة](/ar/admin/billing/payments/refunds) إلا على الحجوزات المستقبلية التي تُنشأ بعد التحديث.
    </Info>

    ## حذف معدات

    1. انتقل إلى **الموارد** \> **المعدات**.
    2. مرّر المؤشر فوق العنصر المطلوب، واضغط قائمة **(...)** بجواره، ثم اختر **حذف** وأكد اختيارك.

    <Warning>
      لا يمكن التراجع عن حذف المعدات. تُحذف جميع الحجوزات المرتبطة بها نهائيًا من دون استرداد ولا يمكن استعادتها، كما لن تعود تحليلات حجوزاتها متاحة.
    </Warning>
