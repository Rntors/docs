---
title: "الصلاحيات"
---

استخدم صلاحيات المسؤول لتقييد الوصول إلى وحدات معينة، وتوزيع المسؤوليات، ومنع الاطلاع على المعلومات الحساسة أو تعديلها.

## فهم الصلاحيات

| الصلاحية | ما تتيحه |
| --- | --- |
| المسؤولون | دعوة المستخدمين وإزالتهم، ومنح دور المسؤول، وإدارة صلاحيات المسؤولين |
| العملاء | دعوة غير المسؤولين، وإزالة غير الأعضاء، وإدارة الشركات وطلبات العضوية والفوترة والدفع والفوترة التلقائيين والأرصدة والملاحظات |
| الفوترة | إدارة الاشتراكات والعقود والفواتير والخطط والحزم والكوبونات والرموز الترويجية |
| الحجوزات | دونها يبقى العرض فقط للموارد، ولا يمكن إنشاء الحجوزات أو إدارتها أو رد مبالغها |
| الخلاصة | دونها يبقى العرض فقط، ولا يمكن إنشاء المنشورات أو تعديلها أو تثبيتها أو حذفها أو حذف التعليقات |
| الفعاليات | دونها يبقى العرض فقط، ولا يمكن إنشاء الفعاليات أو إدارتها أو إدارة التذاكر ورد مبالغها |
| المتجر | دونها يمكن عرض المنتجات والطلبات فقط، ولا يمكن إدارتها أو رد مبالغ الطلبات |
| المزايا | دونها يمكن العرض فقط، ولا يمكن إضافة المزايا أو إدارتها |
| الدعم | دونها يمكن عرض التذاكر والأدلة فقط، ولا يمكن إنشاؤها أو إدارتها |
| التحليلات | دونها لا يمكن فتح صفحة التحليلات |
| الإعدادات | دونها لا يمكن تعديل إعدادات الموقع والتكاملات، وتصبح الخطط والحزم والخصومات والموارد للعرض فقط |

### اعتبارات مهمة

1. إذا [تحول المالك إلى مسؤول](/ar/admin/administration/administrators/owner)، يحصل على كل الصلاحيات.
2. يتلقى المسؤول إشعارات الوحدات المسموح له بها فقط، حتى لو فعّل إشعارات وحدات أخرى في [إعدادات الإشعارات](/ar/admin/administration/your-account/notifications/set-up-notifications).

## تخصيص الصلاحيات

يمكن ضبطها عند [دعوة مسؤول](/ar/admin/customer-management/users/members#دعوة-عضو) أو تعديل مسؤول حالي:

1. افتح **العملاء** واختر المسؤول.
2. اضغط **(...)** \> **تعديل**.

![فتح التعديل](/images/administration-roles-permissions-1.png)

3. اضبط الصلاحيات واضغط **حفظ**.

![تحديد الصلاحيات](/images/administration-roles-permissions-2.png)

## أفضل الممارسات

- **مدير الحساب:** فعّل كل الصلاحيات لدعوة الأعضاء وإنشاء الشركات وإدارة الاشتراكات والمحتوى.
- **مدير الفعاليات:** فعّل **الخلاصة** و**الفعاليات**.
- **المحاسب:** فعّل **التحليلات** لتنزيل تقارير المدفوعات والفواتير.

<Info>
  تتوفر الصلاحيات المخصصة في خطة Business الجديدة، وفي Pro وما فوق ضمن الخطط القديمة. [رقِّ اشتراكك](/ar/admin/administration/billing/make-changes-to-rntor-subscription) للحصول عليها.
</Info>
