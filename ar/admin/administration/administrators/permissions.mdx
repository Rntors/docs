title: "الصلاحيات"

استخدم الصلاحيات لتقييد الوصول إلى وحدات محددة، وتوزيع المسؤوليات، ومنع الاطلاع على المعلومات الحساسة أو تعديلها.

## فهم الصلاحيات

| **الصلاحية** | **الوصف** |
| --- | --- |
| المسؤولون | دعوة المستخدمين وإزالتهم، ومنح دور المسؤول، وإدارة صلاحيات المسؤولين. |
| العملاء | دعوة غير المسؤولين، وإزالة غير الأعضاء، وإدارة الشركات وطلبات العضوية وبيانات الفوترة والدفع التلقائي والفوترة التلقائية والأرصدة والتصاريح والملاحظات. |
| الفوترة | إنشاء الاشتراكات والعقود وإدارتها، وإصدار الفواتير، وإعداد الخطط والحزم والقسائم والرموز. |
| الحجوزات | يبقى العرض فقط للموارد؛ من دونها لا يمكن إنشاء حجوزات أو إدارتها أو رد قيمتها. |
| الخلاصة | يبقى العرض فقط؛ من دونها لا يمكن إنشاء المنشورات أو تعديلها أو تثبيتها أو حذفها أو حذف التعليقات. |
| الفعاليات | يبقى العرض فقط؛ من دونها لا يمكن إنشاء الفعاليات وإدارتها أو إدارة التذاكر ورد قيمتها. |
| المتجر | يبقى عرض المنتجات والطلبات؛ من دونها لا يمكن إدارتها أو رد قيمة الطلبات. |
| المزايا | يبقى عرض المزايا والطلبات؛ من دونها لا يمكن إضافة المزايا أو إدارتها. |
| الدعم | يبقى عرض التذاكر والأدلة؛ من دونها لا يمكن إنشاؤها أو إدارتها. |
| التحليلات | من دونها لا يمكن فتح صفحة التحليلات. |
| الإعدادات | من دونها لا يمكن فتح إعدادات الموقع والتكاملات أو تعديلها، وتصبح الخطط والحزم والخصومات والموارد للعرض فقط. |

### اعتبارات مهمة

1. إذا تحول المالك إلى مسؤول، يحصل على جميع الصلاحيات.
2. يستلم المسؤول إشعارات الوحدات التي يملك صلاحيتها فقط، حتى لو فعّل إشعارات أخرى في [صفحة الإشعارات](/ar/admin/administration/your-account/notifications/set-up-notifications).

## تخصيص الصلاحيات

يمكن ضبطها عند [دعوة مسؤول](/ar/admin/customer-management/users/members#invite-a-member) أو تعديل مسؤول قائم:

1. انتقل إلى **العملاء** وافتح المسؤول.
2. اضغط على **(...) \> تعديل**. <img src="/images/administration-roles-permissions-1.png" alt="تعديل المسؤول" />
3. اضبط الصلاحيات واضغط على **حفظ**. <img src="/images/administration-roles-permissions-2.png" alt="اختيار الصلاحيات" />

## أفضل الممارسات

- **مدير الحساب:** جميع الصلاحيات لدعوة الأعضاء والشركات وإدارة الاشتراكات والمحتوى.
- **مدير الفعاليات:** الخلاصة والفعاليات فقط.
- **المحاسب:** التحليلات لتنزيل تقارير المدفوعات والفواتير.

<Info>
  يتوفر تخصيص الصلاحيات في خطة Pro فما فوق من الخطط القديمة وفي خطة Business الجديدة. [رقِّ اشتراكك إلى Business](/ar/admin/administration/billing/make-changes-to-rntor-subscription) للحصول عليه.
</Info>
