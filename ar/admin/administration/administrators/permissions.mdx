استخدم الصلاحيات لتحديد مهام كل مسؤول في المواقع التي يديرها. تظل بعض الوحدات متاحة للعرض عند تعطيل التعديل؛ لذلك لا يعني إيقاف صلاحية بالضرورة إخفاء الوحدة أو أسعارها.

## تخصيص الصلاحيات

اضبط الصلاحيات عند [دعوة مسؤول](/ar/admin/administration/administrators/administrators#دعوة-مسؤول)، أو غيّرها لاحقًا:

1. افتح **الإعدادات** من القائمة الجانبية، ثم اختر **المسؤولون**.
2. افتح قائمة **(...)** بجوار المسؤول، ثم اختر **تعديل**.
3. فعّل الصلاحيات المطلوبة أو عطّلها.
4. اضغط **حفظ**.

يحصل المالكون والمسؤولون العامون على كل الصلاحيات في جميع المواقع. تنطبق مفاتيح الصلاحيات المنفصلة على دور **مسؤول**.

## فهم الصلاحيات

| الصلاحية | ما تتحكم فيه |
| --- | --- |
| **العملاء** | دعوة الأعضاء وإزالتهم، وحذف غير الأعضاء، وإدارة الشركات وطلبات العضوية. إدارة بيانات فوترة العملاء وطرق الدفع و**الدفع التلقائي** وأرصدة الاعتمادات والتصاريح اليومية والملاحظات، وإعادة إرسال الفواتير. تتطلب إزالة عضو أو شركة لديها اشتراك صلاحية **الفوترة** أيضًا. |
| **الفوترة** | إنشاء العقود والاشتراكات والفواتير والإشعارات الدائنة وإدارتها، وتحديد المدفوعات الخارجية المعلّقة كمدفوعة أو ملغاة، وتعديل الملاحظات الداخلية للمعاملات، وإعداد الخطط والحزم والكوبونات والرموز الترويجية. دونها تظل الخطط والاشتراكات والفواتير متاحة للعرض، بما فيها الأسعار. |
| **الموارد** | إنشاء الموارد وتعديلها وحذفها، وإنشاء الحجوزات وإدارتها ورد مبالغها، وإنشاء [التخصيصات](/ar/admin/resource-management/resources/manage-resource-rentals-with-assignments) وإدارتها. دونها تظل **الغرف** و**المكاتب** و**المكاتب الخاصة** و**مواقف السيارات** و**المعدات** للعرض فقط، بما فيها أسعار الموارد والحجوزات. |
| **الخلاصة** | إنشاء المنشورات وتعديلها وتثبيتها وحذفها، وحذف تعليقات المستخدمين. دونها تظل الخلاصة للعرض فقط. |
| **الفعاليات** | إنشاء الفعاليات وإدارتها، وإدارة التذاكر ورد مبالغها. دونها تظل الفعاليات للعرض فقط. |
| **المتجر** | إنشاء المنتجات والطلبات وإدارتها ورد مبالغ الطلبات. تظل المنتجات والطلبات متاحة للعرض دونها. |
| **المزايا** | إضافة المزايا وإدارتها. تظل المزايا وطلباتها متاحة للعرض دونها. |
| **الدعم** | فتح تذاكر المستخدمين الآخرين، وإنشاء التذاكر والأدلة وإدارتها، وإسناد التذاكر إلى المسؤول. دونها يمكن للمسؤول عرض قائمة التذاكر وجميع الأدلة، لكن لا يمكنه فتح تذاكر أنشأها مستخدمون آخرون. |
| **التحليلات** | فتح **التحليلات** ورؤية التخصيصات في صفحة **التخصيصات**. يتطلب كلاهما هذه الصلاحية. |
| **الإعدادات** | فتح **إعدادات الموقع** و**التكاملات**. لا يمكن الوصول إليهما دون هذه الصلاحية. |

### اعتبارات مهمة

- لكل مسؤول مجموعة صلاحيات واحدة تُطبّق على جميع المواقع التي يديرها.
- يحصل المالكون والمسؤولون العامون دائمًا على كل الصلاحيات في جميع المواقع. إذا تغيّر دور مالك إلى **مسؤول**، يحتفظ بكل الصلاحيات والوصول إلى جميع المواقع إلى أن تعدّل هذا الوصول.
- لا تمنح [تفضيلات الإشعارات](/ar/admin/administration/your-account/notifications/set-up-notifications) صلاحيات إضافية. يلزم أيضًا امتلاك الصلاحية المناسبة: تتطلب إشعارات دفع الفواتير **العملاء**، وتتطلب إشعارات الحجوزات **الموارد**.
- يستطيع أي مسؤول في الموقع [تسجيل حضور المستخدمين](/ar/admin/check-ins)، مهما كانت مفاتيح صلاحياته.
- تعتمد إدارة المسؤولين على [الدور الإداري](/ar/admin/administration/administrators/administrators#فهم-الأدوار-الإدارية)، وليس على صلاحية منفصلة باسم **المسؤولون**.

## أفضل الممارسات

اختر الصلاحيات وفق مهام الشخص:

| مسؤولية الفريق | الصلاحيات المقترحة |
| --- | --- |
| **مدير الحساب** | كل الصلاحيات لإدارة الأعضاء والشركات والاشتراكات ومحتوى الموقع. |
| **مدير الفعاليات** | **الخلاصة** و**الفعاليات** لإدارة المنشورات والفعاليات والتسجيلات. |
| **المحاسب** | **التحليلات** و**الفوترة** لاستخدام التحليلات وتصدير المدفوعات والفواتير من صفحتي **المعاملات** و**الفواتير**. |

## الأسئلة الشائعة

<Accordion title="هل يستطيع المسؤول عرض وحدة إذا كانت صلاحيتها معطّلة؟">
  عادةً يحتفظ بالعرض فقط. الاستثناءات هي **التحليلات** و**إعدادات الموقع** و**التكاملات**؛ إذ تتطلب الصلاحيات المناسبة. يتطلب فتح تذكرة أنشأها مستخدم آخر صلاحية **الدعم**. وتتطلب رؤية التخصيصات **التحليلات**، بينما يتطلب إنشاؤها أو إدارتها **الموارد** أيضًا.
</Accordion>

<Accordion title="هل يمكنني إخفاء الأسعار عن مسؤول؟">
  لا. يمكن للمسؤولين عرض أسعار الخطط والاشتراكات والفواتير والموارد والحجوزات مهما كانت الصلاحيات. تعطيل صلاحية التعديل المناسبة يقيّد إجراءات مثل الإنشاء والتعديل ورد المبالغ، لكنه لا يخفي الأسعار.
</Accordion>
