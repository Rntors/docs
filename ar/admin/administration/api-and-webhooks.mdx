ابنِ مسارات عمل وتكاملات مخصصة بين RNTOR والمنصات الخارجية باستخدام API وWebhooks.

## الحصول على الوصول

1. ينقر [المالك](/ar/admin/administration/administrators/owner) على اسم الشبكة أعلى اليسار.
2. ينتقل إلى **إعدادات الشبكة \> المطورون**.
3. إذا لم تكن مشتركًا، [اشترك في إضافة API وWebhooks](/ar/admin/administration/billing/make-changes-to-rntor-subscription).
4. انسخ Client ID وClient Secret.
5. استخدم المستندات:
   - [مستندات API وبيانات تواصل المطورين](/ar/api-reference/authentication)
   - [مستندات Webhooks](/ar/webhooks/introduction)

![بيانات API](/images/administration-api-&-webhooks-1.png)

<Tip>
  لأي أسئلة أو مشكلات متعلقة بـAPI، تواصل معنا عبر [api@rntor.com](mailto:api@rntor.com).
</Tip>

## آلية العمل

**API**

- جسر ثنائي الاتجاه يتيح لبرامجك الخارجية، مثل CRM أو نظام التحكم في الوصول، طلب المعلومات من RNTOR وإرسال الأوامر إليها.
- يمكّنك من بناء مسارات عمل مخصصة وربط مكوّناتك التقنية مباشرةً.

**Webhooks**

- إشعارات آلية لحظية ترسلها RNTOR إلى تطبيقك.
- ترسل RNTOR طلب webhook إلى رابط تحدده عند وقوع حدث، مثل إنشاء حجز أو إضافة مستخدم أو انتهاء اشتراك.
- تحافظ على تحديث الأنظمة المتصلة فورًا من دون الاستعلام المستمر.

## إعادة إنشاء بيانات API

إذا وصل شخص سابقًا إلى بياناتك وتحتاج إلى إبطالها، يستطيع [المالك](/ar/admin/administration/administrators/owner) إعادة إنشائها، ولن يراها غيره:

1. انقر على اسم الشبكة.
2. انتقل إلى **إعدادات الشبكة \> المطورون**.
3. اضغط على **إعادة إنشاء بيانات الاعتماد**.

<Warning>
  بعد إعادة الإنشاء، تصبح البيانات السابقة غير صالحة ولا يمكن استخدامها للوصول إلى API.
</Warning>
