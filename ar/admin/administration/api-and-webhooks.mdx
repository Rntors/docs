أنشئ مسارات عمل وتكاملات مخصصة بين RNTOR والمنصات الخارجية باستخدام API وWebhooks.

## الحصول على الصلاحية

يتبع [المالك](/ar/admin/administration/administrators/owner) الخطوات الآتية:

1. اضغط اسم الشبكة أعلى اليسار.
2. افتح **إعدادات الشبكة** \> **المطورون**.
3. إذا لم تكن مشتركًا، [أضف API وWebhooks إلى اشتراكك](/ar/admin/administration/billing/make-changes-to-rntor-subscription).
4. انسخ Client ID وClient Secret.
5. استخدم:
   - [وثائق API وبيانات التواصل مع المطورين](/ar/api-reference/authentication)
   - [وثائق Webhooks](/ar/webhooks/introduction)

![بيانات API](/images/administration-api-&-webhooks-1.png)

<Tip>
  للأسئلة أو المشكلات المتعلقة بـAPI، تواصل معنا عبر [api@rntor.com](mailto:api@rntor.com).
</Tip>

## آلية العمل

**API**

- جسر ثنائي الاتجاه يسمح للبرامج الخارجية بطلب المعلومات من RNTOR وإرسال الأوامر إليه.
- يتيح بناء مسارات مخصصة وربط RNTOR مباشرة بمنصاتك الأخرى.

**Webhooks**

- إشعارات آلية لحظية من RNTOR إلى تطبيقك.
- يرسل RNTOR طلبًا إلى الرابط الذي تحدده عند وقوع حدث، مثل إنشاء حجز أو إضافة مستخدم أو انتهاء اشتراك.
- تبقى الأنظمة المتصلة محدّثة دون الاستعلام المستمر.

## إعادة إنشاء بيانات الاعتماد

إذا احتجت إلى إبطال البيانات القديمة، يستطيع [المالك](/ar/admin/administration/administrators/owner):

1. فتح **إعدادات الشبكة** \> **المطورون**.
2. الضغط على **إعادة إنشاء بيانات الاعتماد**.

<Warning>
  تصبح بيانات الاعتماد السابقة غير صالحة فورًا، ولا يمكن استخدامها للوصول إلى API.
</Warning>
