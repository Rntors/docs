أكمل الخطوات الأربع التالية للاستعداد لتطبيقاتك.

## 1. التسجيل في Apple Developer Program

- جهّز Apple Account للمؤسسة أو [أنشئه](https://account.apple.com/).
- احصل على رقم D‑U‑N‑S من [هنا](https://www.dnb.com/duns/get-a-duns.html).
- تتقاضى Apple **99 دولارًا أمريكيًا لكل سنة عضوية**، أو السعر المحلي الظاهر أثناء [التسجيل](https://developer.apple.com/help/account/membership/program-enrollment/).
- قد تحصل المؤسسات غير الربحية المؤهلة في بعض الدول على [إعفاء](https://developer.apple.com/support/membership-fee-waiver/).
- [سجّل كمؤسسة](https://developer.apple.com/programs/enroll/) باستخدام Apple Account ورقم D‑U‑N‑S.
- قد تستغرق العملية حتى أسبوعين حسب الدولة.

<Warning>
  **التسجيل كفرد غير مدعوم.** سجّل كمؤسسة برقم D‑U‑N‑S. ويتطلب ذلك امتلاك صلاحية إبرام الاتفاقيات القانونية مع Apple نيابةً عن المؤسسة. لا يستطيع المالك الفردي أو النشاط المكوّن من شخص واحد التسجيل كمؤسسة.
</Warning>

## 2. تجهيز الحساب لإرسال التطبيق

تلزم Apple المطورين بتقديم حالة التاجر لتوزيع تطبيق جديد أو تحديث داخل الاتحاد الأوروبي امتثالًا لقانون الخدمات الرقمية:

1. افتح قسم [Business](https://appstoreconnect.apple.com/business).
2. اضغط **Complete Compliance Requirements** واختر حالة التاجر، ثم أكمل الخطوات.

<Tip>
  راجع [توثيق Apple](https://developer.apple.com/help/app-store-connect/manage-compliance-information/manage-european-union-digital-services-act-trader-requirements/) لفهم حالة التاجر.
</Tip>

## 3. دعوتنا إلى حساب Apple Developer

لنشر التطبيق باسم حسابك وصيانته، ادعُ فريقنا كمسؤولين في App Store Connect:

1. سجّل الدخول إلى [App Store Connect](https://appstoreconnect.apple.com/).
2. افتح **Users and Access** واضغط **\+**.
3. أدخل:

| **الحقل** | **القيمة** |
| --- | --- |
| الاسم الأول | Rntor |
| اسم العائلة | Support |
| البريد | [support@rntor.com](mailto:support@rntor.com) |
| الدور | Admin |
| موارد المطور | Access to Certificates, Identifiers & Profiles |

<Warning>
  لا يستطيع فريقنا النشر دون دور Admin والوصول إلى الشهادات.
</Warning>

4. اضغط **Invite** لإرسال الدعوة إلى فريق نشر Rntor.

<Tip>
  قد تصلك رسائل تشغيلية من Apple عند قبول إصدار أو ورود رسالة من فريق المراجعة. يمكن تجاهلها لأن فريق المنتج يتلقاها ويتولى النشر، وسنخبرك إذا كان هناك إجراء مهم.
</Tip>

## 4. إنشاء مفتاح App Store Connect API

استخدم جهاز كمبيوتر واتبع [إرشادات Apple لإنشاء المفتاح](https://developer.apple.com/documentation/AppStoreConnectAPI/creating-api-keys-for-app-store-connect-api):

1. افتح **Users and Access** > **Integrations** > **App Store Connect API** > **Team Keys**.
2. اضغط **Generate API Key** أو **\+**، وسمِّ المفتاح، واختر **Admin**، ثم اضغط **Generate**.
3. اضغط **Download API Key** لحفظ ملف **.p8**. تتيح Apple تنزيله مرة واحدة؛ احتفظ به بأمان.
4. سجّل **Key ID** و**Issuer ID** الظاهرين في الصفحة.

<Warning>
  استخدم مفتاحًا بدور **Admin**؛ لا يقبل Rntor الصلاحيات الأقل. إذا كان مفتاحك بدور أقل، فأنشئ مفتاح Admin وألغِ المفتاح القديم.
</Warning>

## ربط الحساب بـ Rntor

افتح **إعدادات الشبكة** > **تطبيق الأعضاء** بصفتك [مالكًا](/ar/admin/administration/administrators/owner). تحت **Apple Developer**، اضغط **متابعة**. بعد منح الوصول، فعّل **I have granted access**، وأدخل **Entity name** و**Team ID** من قسم **Membership Details** في حساب Apple Developer، ثم اضغط **Continue**.

للتطبيق الجديد، تابع [إعداد التطبيق](/ar/admin/general/member-mobile-app/get-started)، وأرسل ملف **.p8** وبيانات **Key ID** و**Issuer ID** مع باقي البيانات.

إذا كان تطبيق iOS منشورًا بالفعل، فافتح **إعدادات الشبكة** > **تطبيق الأعضاء** بصفتك المالك، واضغط **متابعة**، ثم ارفع ملف **.p8**، وأدخل **Key ID** و**Issuer ID** وأرسل البيانات.
