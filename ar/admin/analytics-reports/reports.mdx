## إنشاء تقرير

انتقل إلى **التحليلات** واضغط على **إنشاء تقرير** أعلى اليسار، ثم اختر نوع التقرير.

![إنشاء تقرير مخصص](/images/analytics/analytics-create-custom-reports-1.png)

## أنواع التقارير

يمكن للمسؤول إنشاء تقارير CSV التالية:

| النوع | المرشحات | الاستخدام |
| :-- | :-- | :-- |
| المستخدمون | الأعضاء، غير الأعضاء | بيانات التواصل والفوترة والاشتراكات والشركة والدور. |
| الشركات | الأعضاء، غير الأعضاء | الشركات وبيانات الاشتراك والفوترة. |
| الاشتراكات | حسب الحالة | الاشتراكات السابقة والنشطة، والخطة وتواريخ البدء والتجديد والانتهاء والسعر والأرصدة وتصاريح اليوم. |
| الفواتير | تاريخ الإصدار أو الإنشاء، العميل، الحالة | الأرقام والملاحظات والإجماليات والضرائب والرصيد والتعديلات والحالة والتواريخ وبيانات العميل وملفات PDF. |
| عناصر الفواتير | تاريخ الإصدار أو الإنشاء، العميل، الحالة | تفاصيل البنود والنوع والوصف والإجمالي والصافي والضريبة والخصومات وحالة الدفع والتواريخ والعميل. |
| الإشعارات الدائنة | تاريخ الإنشاء | الإشعارات والفواتير المرتبطة وسبب الإصدار والمبالغ والتعديلات والتواريخ والعميل وPDF. |
| المعاملات | النقود، الأرصدة، تصاريح اليوم، التواريخ، العميل، الحالة، النوع | التاريخ والنوع والوصف والإجمالي والمسترد والمتنازع عليه والدفع والعميل والإيصال. |
| الحجوزات | تاريخ الإنشاء أو البدء، نوع المورد، المورد | المورد والتواريخ والمدة والسعر والدفع والعميل. |
| حضور الفعاليات | وقت الانضمام، الفعالية | الحاضرون وبيانات التواصل والفعالية ودفع التذكرة. |
| الطلبات | وقت الإنشاء، المنتج | منتجات المتجر وخياراتها وأسعارها وبيانات المستخدم. |
| طلبات المزايا | وقت الطلب، الميزة | التعليق والميزة وبيانات المستخدم. |
| الزوار | الزيارات، جهات الاتصال، وقت التسجيل | الزيارات وجهات الاتصال وتواريخها وبيانات الزائر والمضيف. |
| تذاكر الدعم | وقت الإنشاء | السؤال الأولي والنوع والحالة والتاريخ ومقدم الطلب والمسؤول. |

### ملاحظات

- يتضمن تقرير **الاشتراكات** جميع الاشتراكات النشطة، والاشتراكات الملغاة أو المنتهية بعد 29 نوفمبر 2024، تاريخ إطلاق التقرير. وقد يتضمن بعض بيانات الأشهر السابقة، لكن السجل التاريخي الشامل متاح لما انتهى أو أُلغي بعد ذلك التاريخ.
- يتضمن تقريري **الفواتير** و**عناصر الفواتير** فواتير جميع المدفوعات بدءًا من 9 ديسمبر 2025. قبل ذلك، كانت المدفوعات الفورية مثل الحجوزات والطلبات والتذاكر تنشئ إيصالات فقط.

**الأسئلة الشائعة**

<Accordion title="كيف أصدّر قائمة جميع المستخدمين؟">
  نزّل تقرير **المستخدمون** من **التحليلات**، وحدد الأعضاء أو غير الأعضاء أو كليهما.
</Accordion>

<Accordion title="كيف أصدّر الأعضاء أصحاب الاشتراك النشط؟">
  نزّل تقرير **الاشتراكات** وأبقِ حالة **نشط** فقط.
</Accordion>

<Accordion title="كيف أحسب متوسط إنفاق العميل؟">
  1. أنشئ تقرير **المعاملات** للفترة وحدد **مدفوعة**.
  2. اجمع عمود المبلغ بالصيغة `=SUM()`.
  3. احسب عدد المشترين الفريدين بالصيغة `=COUNTUNIQUE(A:A)`.
  4. اقسم إجمالي الإيراد على عدد العملاء الفريدين.
</Accordion>

<Accordion title="كيف أحسب نسبة إشغال الغرف خلال ساعات العمل؟">
  افتح **التحليلات** \> **الإشغال** لعرض المعدل الحالي. [استخدم صفحة الإشغال](/ar/admin/analytics-reports/track-occupancy).

  أو نزّل تقرير **الحجوزات** للغرف والفترة، واجمع مدد الحجوزات للحصول على الساعات المحجوزة. احسب الساعات المتاحة: `عدد الغرف × ساعات العمل اليومية × أيام العمل`. اقسم المحجوز على المتاح واضرب في 100.
</Accordion>

<Accordion title="كيف أحصل على مدفوعات عميل محدد؟">
  أنشئ تقرير **الفواتير** للملخص أو **عناصر الفواتير** للتفاصيل، ثم صفِّ حسب **العميل**. ويمكنك أيضًا تنزيل الفواتير والإيصالات من **الفوترة** \> **الفواتير** أو **المعاملات**.
</Accordion>

<Accordion title="أين أجد توزيع الصافي والإجمالي والضريبة لكل دفعة؟">
  أنشئ تقرير **عناصر الفواتير**.
</Accordion>

<Accordion title="أين أجد الإيراد حسب اسم الخطة؟">
  أنشئ تقرير **عناصر الفواتير** وراجع أسماء الخطط في عمود **الوصف**.
</Accordion>
