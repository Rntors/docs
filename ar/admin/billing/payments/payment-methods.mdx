يمكن للمستخدمين الاختيار من عدة طرق للدفع عند إجراء حجز أو عملية شراء. وتختلف الطرق المتاحة للمسؤولين قليلًا؛ إذ يمكنهم وحدهم استخدام طرق معينة، مثل **مجاني** و**الدفع الخارجي**، والمخصصة لحالات محددة.

| طريقة الدفع | متاحة في بوابة المسؤول | متاحة في بوابة الأعضاء |
| --- | :-: | :-: |
| **مجاني** | ✓ |  |
| **الدفع الخارجي** | ✓ |  |
| **الأرصدة** | ✓ | ✓ (للأعضاء فقط) |
| **تصاريح اليوم** | ✓ | ✓ (للأعضاء فقط) |
| **الفاتورة** | ✓ | ✓ |
| **طريقة دفع محفوظة** (بطاقة أو حساب مصرفي) | ✓ | ✓ |
| **طريقة دفع جديدة** |  | ✓ |

## طريقة الدفع المجاني

- تتوفر طريقة **مجاني** حصريًا للمسؤولين في بوابة المسؤول، شريطة امتلاكهم [صلاحية الحجوزات](/ar/admin/administration/administrators/permissions).
- تتيح للمسؤولين إنشاء حجوزات لأنفسهم أو للعملاء مجانًا، من دون خصم أي مبلغ مالي أو رصيد.

## طريقة الدفع الخارجي

- تتوفر [طريقة الدفع الخارجي](/ar/admin/billing/payments/external) حصريًا للمسؤولين في بوابة المسؤول عند إنشاء حجوزات للعملاء.
- تُستخدم لتسجيل المدفوعات المستلمة خارج RNTOR.

## الأرصدة

- تتوفر [طريقة الدفع بالأرصدة](/ar/admin/billing/credits-and-day-passes/credits) للأعضاء عند حجز الموارد أو شراء تذاكر الفعاليات أو الطلب من المتجر، إذا تحققت الشروط التالية:
  - تفعيل الأرصدة في الموقع.
  - تحديد سعر الخدمة بالأرصدة.
  - تخصيص أرصدة للعضو أو شراؤه لها.
- يمكن للمسؤولين أيضًا استخدام الأرصدة عند إنشاء حجز لعضو يمتلك رصيدًا.

يوجد نوعان من الأرصدة:

- **الأرصدة الشخصية** ويستخدمها الأعضاء بصورة فردية.
- **أرصدة الشركة** ويستخدمها أعضاء الشركة ومديروها. ويخضع استخدامها من جانب أعضاء الشركة [لصلاحيات طرق الدفع في الشركة](/ar/admin/customer-management/companies/company-payment-method-permissions).

## تصاريح اليوم

- تظهر [طريقة الدفع بتصاريح اليوم](/ar/admin/billing/credits-and-day-passes/day-passes) للأعضاء عند حجز المكاتب المرنة، إذا تحققت الشروط التالية:
  - تفعيل تصاريح اليوم في الموقع.
  - تفعيل خيار **تصاريح اليوم** للمكتب المرن المحدد.
  - امتلاك العضو اشتراكًا شخصيًا أو اشتراك شركة يتضمن تصاريح يوم.
- يمكن للمسؤولين أيضًا استخدام تصاريح اليوم عند إنشاء حجز لعضو يمتلك تصاريح يوم.

يوجد نوعان من تصاريح اليوم:

- **تصاريح اليوم الشخصية** ويستخدمها الأعضاء بصورة فردية.
- **تصاريح يوم الشركة** ويستخدمها أعضاء الشركة ومديروها. ويخضع استخدامها من جانب أعضاء الشركة [لإعدادات الشركة](/ar/admin/customer-management/companies/company-payment-method-permissions).

## الفاتورة

- تتيح طريقة الدفع **بالفاتورة** إضافة المدفوعات إلى فاتورة بدلًا من تحصيلها فورًا.
- يمكن للعملاء استخدام طريقة الدفع **بالفاتورة** لحجوزات الموارد وتذاكر الفعاليات وطلبات المتجر وشراء حزم الأرصدة، إذا كان خيار [الدفع عبر الفاتورة](/ar/admin/billing/payments/pay-with-invoice) مفعّلًا لهم.
- يمكن للمسؤولين استخدام [طريقة الدفع بالفاتورة](/ar/admin/billing/payments/pay-with-invoice) عند إنشاء حجز لأي عميل.

يوجد نوعان من طريقة الدفع **بالفاتورة**:

- **الفاتورة الشخصية** ويستخدمها العملاء بصورة فردية.
- **فاتورة الشركة** ويستخدمها أعضاء الشركة ومديروها. ويخضع استخدامها من جانب أعضاء الشركة [لإعدادات الشركة](/ar/admin/customer-management/companies/company-payment-method-permissions).

## طريقة دفع جديدة

- يتوفر خيار **طريقة دفع جديدة** لجميع المستخدمين في بوابة الأعضاء على الويب وتطبيق الجوال، إذا تحققت الشروط التالية:
  - ربط [بوابة دفع](/ar/admin/billing/payments/payment-gateway).
  - تفعيل خيار **المال** للمورد أو الخدمة وتحديد سعر نقدي لهما.
- يتيح هذا الخيار للمستخدمين إدخال بيانات دفع جديدة لإتمام المعاملة فورًا.

## طريقة دفع محفوظة

### بطاقة ائتمان محفوظة

- تظهر بطاقة الائتمان المحفوظة للمستخدمين في جميع أنواع المدفوعات، إذا:
  - سبق لهم إجراء دفعة واحدة على الأقل، أو [أضافوا](/ar/admin/billing/payments/payment-gateway#add-a-payment-method) بيانات بطاقتهم يدويًا.
  - كانت بوابة الدفع المتصلة [تدعم حفظ طرق الدفع](/ar/admin/billing/payments/payment-gateway#manage-payment-methods).
- يمكن للمسؤولين أيضًا استخدام بطاقات العملاء المحفوظة لإنشاء حجز نيابةً عن العميل، أو تحصيل قيمة فواتيره، أو [إنشاء مدفوعات لمرة واحدة](/ar/admin/billing/payments/create-one-off-payments) في RNTOR.

### حساب مصرفي محفوظ

- يظهر الحساب المصرفي المحفوظ خصيصًا لمدفوعات الفواتير، إذا:
  - كانت بوابة الدفع المتصلة تدعم حفظ الحسابات المصرفية.
  - سبق للعميل إجراء دفعة واحدة على الأقل، أو [أضاف](/ar/admin/billing/payments/payment-gateway#add-a-payment-method) بيانات حسابه المصرفي يدويًا.
- يمكن للمسؤولين أيضًا استخدام الحسابات المصرفية المحفوظة لدى العملاء لتحصيل قيمة فواتيرهم.

## الأسئلة الشائعة

<Accordion title="ما طرق الدفع المتاحة لي بصفتي مسؤولًا عند إنشاء حجز نيابةً عن عميل؟">
  عند إنشاء حجز نيابةً عن عضو، يمكن للمسؤولين استخدام طرق الدفع التالية:

  - [الدفع الخارجي](/ar/admin/billing/payments/external)
  - الأرصدة الشخصية للعضو أو أرصدة شركته
  - تصاريح اليوم الشخصية للعضو أو تصاريح شركته
  - الفاتورة الشخصية للعضو أو فاتورة شركته
  - طرق الدفع المحفوظة لدى العضو

  عند إنشاء حجز نيابةً عن غير عضو، تتوفر للمسؤولين طرق الدفع التالية:

  - [الدفع الخارجي](/ar/admin/billing/payments/external)
  - [الفاتورة الشخصية](/ar/admin/billing/payments/pay-with-invoice)
  - طرق الدفع المحفوظة لدى غير العضو
</Accordion>

<Accordion title="كيف أتيح لموظفيّ أو فريقي حجز الغرف أو الموارد الأخرى مجانًا؟">
  1. [أضفهم كمسؤولين](/ar/admin/administration/administrators/administrators) ومنحهم [صلاحية الحجوزات](/ar/admin/administration/administrators/permissions).
  2. عند حجز غرفة أو مكتب أو مورد آخر، ستظهر للمسؤولين طريقة الدفع **مجاني**.
</Accordion>
