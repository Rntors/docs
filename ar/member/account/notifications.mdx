تطلع الإشعارات المستخدم على التحديثات والتذكيرات والإجراءات المرتبطة بحسابه.

## الاستلام والإدارة

### الإشعارات الفورية

تُرسل كل الإشعارات فوريًا افتراضيًا، عدا دعوات الأعضاء ورسائل التأكيد ورسائل الزوار. يمكن السماح بها من تطبيق الأعضاء أو بوابة الويب وفق [إرشادات الإشعارات](/ar/admin/administration/your-account/notifications/set-up-notifications).

### البريد

بعض الرسائل إلزامية ولا يمكن تعطيلها، وبعضها اختياري يديره المستخدم من **الحساب** \> **الإشعارات**.

![تفضيلات المستخدم](/images/member-account-notifications-1.png)

عند تفعيل البريد يصل الإشعار بالبريد وفوريًا؛ وعند تعطيله يصل فوريًا فقط.

## أنواع الإشعارات

| الإشعار | متى يُرسل | فوري | بريد |
| --- | --- | --- | --- |
| دعوة حجز | عند إنشاء المسؤول أو [مدير الشركة](/ar/admin/customer-management/companies/company-members-and-managers) حجزًا لك أو إضافتك مدعوًا | إذا اختار المنشئ | اختياري؛ مفعّل افتراضيًا |
| تحديث حجز | عند تعديل التاريخ أو الوقت أو المقاعد أو العنوان أو الملاحظة أو التكرار | إذا اختار المعدّل | إذا اختار المعدّل |
| تذكير بدء أو نهاية الحجز | قبل البداية أو النهاية بـ5 دقائق | ✓ | اختياري؛ معطّل افتراضيًا |
| تحديثات الاشتراك | الإنشاء وتراكم الرصيد أو انتهاؤه والتذكير بالنهاية | ✓ | اختياري؛ مفعّل |
| طلبات المجتمع | تحديث طلب الانضمام | ✓ | اختياري؛ مفعّل |
| تعديل الرصيد | منح المسؤول رصيدًا أو خصمه | ✓ | اختياري؛ معطّل |
| منشورات وتعليقات الخلاصة | منشور جديد أو تعليق ذي صلة | ✓ | اختياري؛ معطّل |
| تذكيرات الفعالية أو إلغاؤها | قبلها بـ24 ساعة وساعة، أو عند الإلغاء | ✓ | اختياري؛ مفعّل |
| تسجيل الزائر أو طلب الزيارة | وصول الزائر أو طلبه زيارتك | ✓ | اختياري؛ مفعّل |
| تذاكر الدعم | الإنشاء والتعليقات وتغيير الحالة أو المكلّف | ✓ | اختياري؛ مفعّل |
| رسائل المحادثة | رسالة جديدة | ✓ | اختياري؛ مفعّل |
| دعوة العضوية | دعوة المسؤول لك | لا | إلزامي |
| تأكيد الدفع | الدفع عبر بوابة | لا | إلزامي |
| إشعارات الزيارة | الدعوة أو التغيير أو الإلغاء | لا | إلزامي |
| رسائل تأكيد أخرى | الحجز والطلب والفعالية والميزة | لا | إذا أعدّها المسؤول |

## إشعارات الفواتير

| الحدث | الإشعار | فوري | بريد |
| --- | --- | --- | --- |
| فاتورة أو تحصيل اشتراك قادم | تذكير قبل التجديد بثلاثة أيام، مع معاينة الفاتورة وتحديث طريقة الدفع | لا | إلزامي |
| إصدار فاتورة | «فاتورتك جاهزة للدفع» مع رابط وPDF | ✓ | إلزامي |
| دفع الفاتورة | معالجة الدفع ثم نجاحه مع تفاصيل وملفات الفاتورة والإيصال | لا | إلزامي |
| فشل التحصيل | طلب طريقة دفع صالحة ورابط للدفع | ✓ | إلزامي |
| إعادة إرسال الفاتورة | تذكير بأنها جاهزة مع الرابط وPDF | لا | إلزامي |
| محاولات الدفع والتذكيرات | وفق [إعدادات المحاولات](/ar/admin/billing/invoices/payment-retries-and-reminders) | لا | يحددها المسؤول؛ مفعّلة افتراضيًا |
| إلغاء الفاتورة | إشعار الإلغاء مع التفاصيل وPDF | ✓ | ✓ |
