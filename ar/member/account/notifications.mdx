تبلغ الإشعارات المستخدم بالتحديثات والتذكيرات والإجراءات المتعلقة بحسابه.

## الاستلام والإدارة

### الإشعارات الفورية

تُرسل جميع الإشعارات فوريًا افتراضيًا، باستثناء دعوات الأعضاء ورسائل التأكيد ورسائل الزوار. يسمح المستخدم بها من [تطبيق الجوال أو بوابة الويب](/ar/admin/administration/your-account/notifications/set-up-notifications#push-notifications).

### رسائل البريد

بعضها إلزامي لا يمكن تعطيله وبعضها اختياري يُدار من **الحساب \> الإشعارات**.

![تفضيلات إشعارات المستخدم](/images/member-account-notifications-1.png)

إذا فُعّل البريد، تصل الإشعارات الاختيارية بالبريد وفوريًا؛ وإذا عُطّل، تصل فوريًا فقط.

## الإشعارات التي يتلقاها المستخدم

| **الإشعار** | **المعنى** | **فوري** | **بريد** |
| :-- | :-- | :-- | :-- |
| دعوات الحجز | حجز أنشأه مسؤول أو [مدير شركة](/ar/admin/customer-management/companies/company-members-and-managers) لك، أو أُضفت مدعوًا | إذا اختار المنشئ | إذا اختار المنشئ وفُعّل البريد؛ مفعّل افتراضيًا |
| تحديثات الحجز | [تعديل](/ar/admin/resource-management/resources/manage-bookings#edit-a-booking) التاريخ أو الوقت أو الكمية أو العنوان أو المذكرة أو التكرار | إذا اختار المحرر | إذا اختار المحرر |
| تذكير البداية والنهاية | قبل البداية أو النهاية بـ5 دقائق | ✓ | اختياري، معطّل افتراضيًا |
| تحديثات الاشتراك | إنشاء الاشتراك واستحقاق/انتهاء الأرصدة والتصاريح والتذكير قبل النهاية بيوم | ✓ | اختياري، مفعّل |
| طلبات المجتمع | تحديث طلب الانضمام | ✓ | اختياري، مفعّل |
| تحديث الأرصدة | منح المسؤول أرصدة أو خصمها | ✓ | اختياري، معطّل |
| منشورات وتعليقات الخلاصة | منشور جديد أو تعليق على منشور شاركت فيه | ✓ | اختياري، معطّل |
| تذكيرات الفعالية وإلغاؤها | قبل الفعالية بـ24 ساعة وساعة، أو إلغاؤها | ✓ | اختياري، مفعّل |
| دخول الزائر وطلبات الزيارة | [وصول الزائر أو طلبه](/ar/member/visitors/check-in-and-check-out) | ✓ | اختياري، مفعّل |
| تذاكر الدعم | إنشاء التذكرة أو تعليق أو تحديث الحالة/المسند إليه | ✓ | اختياري، مفعّل |
| رسائل الدردشة | رسالة جديدة | ✓ | اختياري، مفعّل |
| دعوة العضو | دعوة المسؤول للانضمام | لا | إلزامي |
| تأكيد الدفع | دفع عبر بوابة | لا | إلزامي |
| إشعارات الزيارة | دعوة أو تعديل أو إلغاء | لا | إلزامي |
| تأكيدات أخرى | الحجز والطلب والفعالية والميزة | لا | إذا أعدها المسؤول |

## إشعارات الفواتير

| **الحدث** | **الإشعار** | **فوري** | **بريد** |
| :-- | :-- | :-- | :-- |
| فاتورة/دفع تلقائي قادم قبل التجديد بـ3 أيام | يوضح تاريخ الجاهزية وطريقة الدفع الافتراضية إن وجدت، مع معاينة الفاتورة وتحديث الطريقة | لا | إلزامي |
| إصدار فاتورة | «فاتورتك جاهزة للدفع» مع رابط وبيانات وPDF | ✓ | إلزامي |
| دفع الفاتورة | رسالتا بدء المعالجة ونجاح الدفع مع تفاصيل وملفات الفاتورة والإيصال | لا | إلزامي |
| فشل التحصيل التلقائي | طلب طريقة دفع صالحة مع رابط للدفع بطريقة بديلة | ✓ | إلزامي |
| إعادة إرسال الفاتورة | تذكير بأنها جاهزة للدفع مع التفاصيل وPDF | لا | إلزامي |
| محاولات الدفع والتذكيرات | وفق [إعداد المحاولات والتذكيرات](/ar/admin/billing/invoices/payment-retries-and-reminders) | لا | إذا أعدها المسؤول؛ مفعّلة افتراضيًا |
| إلغاء الفاتورة | إشعار الإلغاء مع التفاصيل وPDF | ✓ | ✓ |

**الأسئلة الشائعة**

<Accordion title="لماذا يتلقى العضو إشعارات المسؤول؟">
  لا تُرسل [إشعارات المسؤول](/ar/admin/administration/your-account/notifications/set-up-notifications) إلا لحسابات المسؤولين. [أزل دور المسؤول](/ar/admin/customer-management/users/remove-users) من العضو لمنعها.
</Accordion>
