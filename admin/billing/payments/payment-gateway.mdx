With a [payment gateway connected](/admin/integrations/payments/overview), users can pay online for supported products and services.

## How users make payments

1. At checkout, the user selects a **saved payment method** or **New payment method**.

<Frame caption="Image placeholder — choosing a payment method">
  **Image placeholder:** payment selection during checkout.
</Frame>

2. For a new method, RNTOR opens the gateway’s secure payment page, where the user chooses from the methods supported by that gateway.

<Frame caption="Image placeholder — payment gateway checkout">
  **Image placeholder:** hosted payment page.
</Frame>

3. RNTOR creates a transaction for every initiated payment.
   - Users check it under **Membership > Billing > Transactions**.
   - Administrators check all location transactions under **Billing > Transactions**.
4. After a successful payment, the user sees confirmation and receives the available invoice and receipt by email.

## Track transactions

Administrators can track and manage transactions from **Billing > Transactions**.

<Frame caption="Image placeholder — Billing > Transactions">
  **Image placeholder:** transactions page with filters.
</Frame>

- Switch between the **Money**, **Credits**, and **Day passes** tabs.
- Filter by **Status**:

| Status | Meaning |
| --- | --- |
| **Paid** | Payment completed successfully. |
| **Pending** | The customer has not completed checkout yet, or an External booking is waiting for payment. |
| **Processing** | The payment was submitted and is awaiting confirmation from the gateway or bank. |
| **Canceled** | Checkout expired or an administrator canceled a pending external transaction. |
| **Failed** | The gateway declined or could not complete the payment. |

- Filter by **Type** to isolate subscriptions, invoices, packages, bookings, tickets, orders, custom payments, and credit/day-pass activity.
- Filter by **Customer** or **Create date** for reconciliation.

## Manage payment methods

When supported by the connected gateway, customers can save payment methods for faster checkout and automatic invoice payments.

### Add a payment method

Customers:

1. Go to **Membership > Billing**.
2. Open the personal or company section.
3. Under **Payment methods**, press **Add** and enter the details through the gateway.

<Frame caption="Image placeholder — member adds a payment method">
  **Image placeholder:** member billing payment methods.
</Frame>

Administrators:

1. Go to **Customers** and open the customer profile.
2. In **Payment methods**, press **Add**.

<Frame caption="Image placeholder — administrator adds a payment method">
  **Image placeholder:** customer profile payment methods.
</Frame>

3. Complete the secure gateway flow and save.

Administrators can use saved methods to create bookings, [charge invoices](/admin/billing/invoices/record-invoice-payments), and [create one-off payments](/admin/billing/payments/create-one-off-payments).

### Set a default payment method

The default method is used for eligible subscription invoice auto-charges.

1. Open **Membership > Billing** or the customer profile.
2. Press **(…)** beside the saved method.
3. Select **Set as default**.

### Change a default payment method

1. Add the replacement payment method.
2. Press **(…)** beside it and select **Set as default**.
3. Delete the old method if it is no longer needed.

### Delete a payment method

Customers or administrators press **(…)** beside the method and select **Delete**.

<Frame caption="Image placeholder — delete a payment method">
  **Image placeholder:** payment method actions menu.
</Frame>

#### Delete a default payment method

A customer with an active subscription must add another method and make it default before deleting the current default. An administrator can instead disable subscription [Auto-pay](/admin/billing/subscriptions/control-invoice-auto-charge) when invoices should no longer be charged automatically.

## FAQs

</Accordion>
