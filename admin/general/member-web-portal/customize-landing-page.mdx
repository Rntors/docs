# Customize landing page

> Customize the appearance of the landing page for your member web portal, including headline and description, cover photos and videos, and control search engine visibility

Member web portal comes with a landing page that works like your marketing site, featuring your brand, locations, and member mobile apps. It includes:

- Logo
- Description
- Headline
- Locations with their photos and addresses
- CTAs for public products and services in each location (Sign up, Rooms, Desks, etc).
- QR code and app store badges for member mobile apps

The landing page is generated automatically based on the information you added to the member web portal. No coding or graphic editing is required.

![Image](/images/member-web-portal-customize-the-landing-page-1.png)

## Access the landing page

Go to the root of your member web portal custom domain to access the landing page. Here are some examples for your inspiration:

- [Creative States](https://members.creativestates.net/)
- [Culture Co-Working](https://membersportal.culturecoworking.ie/)

## Customize the landing page

The language in which the landing page is displayed for all users is determined by your network language. [Manage network language](/admin/general/language)

### Header section

![Image](/images/member-web-portal-customize-the-landing-page-2.png)

1. Go to RNTOR [as an owner](/admin/administration/administrators/owner), click **(...)** menu next to your network name on the left-side panel \> **Network** **settings.**
2. Go to **General** \> **Information** tab to customize the network name and email footer.
3. Go to **General** \> **Branding** tab to customize the logo, accent color for buttons and the font.
4. Go to **Member web portal** \> **Landing page** tab to customize the headline, description that appears below "Welcome to ..." and index in search machines.
5. Set up the [custom domain name](/admin/general/member-web-portal/custom-domain-for-your-member-web-portal) if you want the landing page to use your own domain name instead of ...rntor.com.
6. As an administrator, [upload location cover photos and videos](/admin/location/information) for each location, which will be displayed in a slide show behind the **Welcome** window.

### Locations section

![Image](/images/member-web-portal-customize-the-landing-page-3.png)

1. Navigate to RNTOR and select the necessary location on the left-side panel \> press **(...)** next to it \> **Location settings** \> go to **General** to [upload a cover photo](/admin/location/information) for each location or update the address.
2. For **Sign Up** CTAs to appear for each location, an administrator can [create membership plans](/admin/billing/plans/set-up-plans) and enable the **Sign Up** property for them.
3. To make other pages appear under the location's name, administrators enable them and [set page visibility](/admin/location/visibility) to **Public** or add content with public visibility to these pages so that everybody can access them.
4. Go to the **Integrations** page and [connect Calendly integration](/admin/integrations/bookings/calendly) to each location for the **Book a tour** CTAs to appear. It will let interested people book a tour with you around the space.

### Member mobile app section

![Image](/images/member-web-portal-customize-the-landing-page-4.png)

[Order Member Mobile App](/admin/general/member-mobile-app/get-started) for the app store badges to appear.

### Control search engine visibility

By default, your landing page is visible to search engines. To control its visibility, log in as an [owner](/admin/administration/administrators/owner) and navigate to the **Network settings \> Member web portal** \> **Landing page** tab. From there, you can manage the **Index in search engines** switch:

- If enabled - you allow search engines to index the landing page and show it in search results. Your member web portal will be visible in search results, making it easy for new customers to find you
- If disabled - you do not allow search engines to index the landing page and show it in search results. Your member web portal will not appear in search results, making it accessible only via a direct link. _It may take time for these third party search engines to de-index your content._
