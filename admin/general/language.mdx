# Language

> See which languages RNTOR supports, learn how to contribute translation improvements, and configure default languages for your network and locations

Administrators can configure the preferred language for the network, each location, and their own account in the admin web portal. Users can set their preferred language for the member web portal and mobile app.

## Supported languages

RNTOR supports the following languages:

- English
- Ukrainian
- Arabic (community)
- Czech (community)
- Danish (community)
- Dutch (community)
- French (community)
- German (community)
- Italian (community)
- Korean (community)
- Norwegian (community)
- Polish (community)
- Portuguese (community)
- Russian (community)
- Spanish (community)
- Swedish (community)

<Info>
  Community translations are **not official,** and their quality is not guaranteed. Contribute to improving them.
</Info>

We use machine translation to translate everything when a new language is added to RNTOR. However, since machine translation may not be accurate, you can contribute improvements. Just [contact our support team](/admin/administration/contact-support) with the exact improvement you suggest to make.

## Network language

The network language setting determines the default language for the following pages:

- The [landing page](/admin/general/member-web-portal/customize-landing-page) of the member web portal for all users.
- The [Terms of use](/admin/general/terms-of-use) and [Privacy policy](/admin/general/privacy-policy) pages.
- The Notifications preferences page opened from the email footer.
- The user login page for connecting to Wi-Fi using [IronWiFi integration](/admin/integrations/wifi/ironwifi).

To change the network language, do the following:

1. Go to RNTOR as an [owner](/admin/administration/administrators/owner) \> click the network name on the left-side panel.
2. Select **Network settings** \> **Member web portal** \> **General** tab
3. In the **Language** property, choose the preferred network language.

## Location language

The location language determines:

- The default language for [member invitations](/admin/customer-management/users/members#invite-a-member). You can change the language of a specific invitation on the invite page.
- The language of the invoice and receipt PDFs.
- The language of emails sent to the company email and accounting email.
- Emails for [visit invitations.](/member/visitors/preregister-and-approve-visit-requests)
- Emails to visitors' hosts with visit requests for approval or rejection.
- Payment gateway transaction descriptions (in your payment gateway's dashboard).

To change the location language, administrators do the following:

1. Go to RNTOR \> press the **(...)** button next to the location name on the left-side panel.
2. Select **Location settings** \> **General** \> **Information** tab.
3. In the **Language** property, choose the preferred location language.
