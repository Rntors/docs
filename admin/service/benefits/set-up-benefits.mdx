# Benefits

> Set up a member benefits page to offer exclusive partner discounts, promotions, and perks. Add and manage benefits, benefit categories, and benefit applications

Offer discounts and exclusive promotions to your customers with the **Benefits** page.

## Enable Benefits

1. Click the menu (…) near the location name on the left-side panel.
2. Go to **Location settings** > **Service** > **Benefits**.
3. Enable the “Benefits” switch.
4. Create benefit categories to group your benefits by type.

<Info>
  By default, benefit categories are sorted alphabetically by title. Drag and drop categories to rearrange their order.
</Info>

![Service Benefits Enable Benefits](/images/service/set-up-benefits-1.png)

## Create a benefit

1. Go to the **Service** > **Benefits** page.
2. Press **Add benefit** in the top right corner and configure it:

| Cover photo           | A picture with a 2x1 ratio.                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Title                 | The title of the benefit.                                                                                                 |
| Subtitle              | Summary of the benefit that appears below its title.                                                                      |
| Description           | Details about the benefit for the customers.                                                                              |
| Category              | Select which category the benefit belongs to.                                                                             |
| Featured              | If enabled, the benefit will be prominently pinned at the top of the **Benefits** page.                                   |
| Application           | If enabled, your customers will be able to apply for a benefit.                                                           |
| Application allowance | Can be set to either **Unlimited** or **Once**.                                                                           |
| CTA button label      | Customize the call-to-action button by selecting one of the options.                                                      |
| Confirmation email    | Enable it to send confirmation emails to your customers and [customize the text](/admin/general/customize-emails) of the email. |
| Visibility            | Set whether the benefit should be visibile to public, network members, location members, or only administrators.          |

## How benefits work

* Customers can explore and apply for benefits on the **Benefits** page. Understand [how users apply for benefits.](/member/benefits)

![Set Up Benefits image 2](/images/service/set-up-benefits-2.png)

* Use the **Promote** feature to create a feed post about the benefit and attract more customer attention to it. This is a great way to announce a new member benefit or bring attention back to an existing one.

![Set Up Benefits image 3](/images/service/set-up-benefits-3.png)

<Info>
  The **Benefits** module is available on the Pro plan and above in RNTOR legacy plans and on the new Business plan. ​ If you’re currently on a legacy plan, [upgrade your subscription to the Business plan](/admin/administration/billing/make-changes-to-rntor-subscription) to access **Benefits**.
</Info>

## Track benefit applications

View all benefit applications on the **Service** > **Benefits** > **Applications** panel. Applications are sorted from newest to oldest, and each has a sequence number (#1, #2, etc.). For every application, you can see the benefit title, sequence number, date and time, and the applicant's name.

![Set Up Benefits image 4](/images/service/set-up-benefits-4.png)

Filter applications to find what you need:

* Filter by **Category** to see applications for benefits in a specific [category](/admin/service/benefits/set-up-benefits).
* Filter by **Benefit** to see applications for a specific benefit.
* Filter by **User** (applicant) to see all applications from a specific customer.
* Filter by **Create date** to see applications submitted on, before, after, or between specific dates.

![Set Up Benefits image 5](/images/service/set-up-benefits-5.png)

To follow up on an application, click it > press the applicant > **Chat** to message them directly.

<Tip>
  [Configure the notifications](/admin/administration/your-account/notifications/set-up-notifications) in the app to instantly receive notifications about new benefit applications.
</Tip>

## Edit or delete a benefit

1. Go to **Service** > **Benefits**.
2. Hover over the benefit > press the menu (…) next to it > **Edit** or **Delete**.

![Service Benefits Edit Or Delete A Benefit](/images/service/set-up-benefits-6.png)

<Warning>
  Deleting a benefit is irreversible and can not be undone.
</Warning>

## Edit or delete a benefit category

1. Go to **Location settings** > **Service** > **Benefits**.
2. Press the menu (…) next to the necessary category > **Edit** or **Delete**.

![Service Benefits Edit Or Delete A Benefit Category](/images/service/set-up-benefits-7.png)

<Warning>
  Deleting a benefit category is irreversible and can not be undone. All benefits from the selected category will be deleted automatically.
</Warning>

**FAQ**

<Accordion title="Why can't I see the Benefits page as an administrator?">
  The visibility of your **Benefits** page is directly controlled by the visibility settings of the individual benefits themselves. If the visibility of all your benefits is set to "Administrators," only administrators will see them in RNTOR. It won't be visible to anyone in the member web portal.

  To check and update benefit visibility, follow [these steps](/admin/service/benefits/set-up-benefits#edit-or-delete-a-benefit).
</Accordion>
