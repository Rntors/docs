Room display helps customers see room availability at a glance, make instant bookings via QR code, and prevents abandoned bookings with a check-in feature.

## How room display availability indicators work

Room display signals room availability by tinting the background color of the tablet.

| **Tablet color** | **Explanation**                                                                                                                        |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Green            | The room is available for booking. The free time until the next booking is longer than the minimum booking duration set for this room. |
| Yellow           | A meeting room will become available in less than 60 minutes.                                                                          |
| Red              | The room is unavailable for the next 60 minutes.                                                                                       |

The display also shows the current and upcoming bookings. Bookings include the full name of the booker, booking title, and time. This helps users understand when the room will be free.

<Info>
  Room display respects users' [privacy settings](/admin/customer-management/users/manage-user-account). If a user selects **Administrators** for their **Booking title visibility**, their booking title will not appear on the display.
</Info>

## How users make ad-hoc bookings with a QR code

![Resource Management Room Display Use Room Display 1](/images/resource-management-room-display-use-room-display-1.png)

Room display shows a unique QR code for the room in the bottom-left corner of the screen.

By scanning the QR code, users are taken to the room’s booking calendar in the member web portal or mobile app, where they can book the room instantly. ​

## How abandoned booking protection works

To prevent no-shows, Room display supports a check-in feature for totally free rooms (with **Money** and **Credits** pricing disabled).

When a booking is made for a room, it is initially created in a **Tentative** status. The booking remains **Tentative** until the user checks in via Room display.

When [creating](/admin/resource-management/resources/set-up-resources) or [editing](/admin/resource-management/resources/set-up-resources) a free room in RNTOR, you can enable and configure **Check in** to prevent abandoned bookings:

* **Abandoned threshold** — defines in how much time after the booking start the booking is auto-removed if nobody checks in. If the threshold is reached without a check-in, the booking status automatically changes to **Canceled**.
* **Early check in** — defines how much time before the booking start the **Check in** button appears and users can check in. Once a user arrives and checks in, the booking status automatically changes to "Confirmed."

![Resource Management Room Display Use Room Display 2](/images/resource-management-room-display-use-room-display-2.png)

Before the meeting, the **Check in** button appears on the room display based on the **Early check in** time you set (e.g., 10 minutes before the booking starts).

![Check In on room display on on RNTOR's coworking space management platform](/images/resource-management-room-display-use-room-display-3.png)

If the user taps **Check in**, the booking is confirmed, and a confirmation message appears on the screen.

![Check In on room display on RNTOR's coworking space management platform](/images/resource-management-room-display-use-room-display-4.png)

If no check-in happens, after the **Abandoned threshold** time passes (e.g., 5 minutes after the booking starts), the booking is automatically removed from the calendar, freeing up the room for others.

## Troubleshoot issues with Room display

If you are having trouble enabling or using the Room display app, here are the most common reasons and how to fix them:

<Accordion title="1. Poor Internet connection">
  If bookings don't appear on the room display or you've faced an issue accessing it, the tablet might have a weak or unstable internet connection. Reconnect the tablet to Wi-Fi or connect to a different network.
</Accordion>

<Accordion title="2. Logged in with the wrong email address">
  To set up Room display for a room in a specific location, you need to be logged in with an [administrator account](/admin/administration/administrators/administrators) for that location.

  [Log out of the app](/admin/resource-management/room-display/set-up-room-display) and log back in with an administrator account that has access to the correct location.
</Accordion>

<Accordion title="3. Outdated app version">
  Make sure you're using the latest version of the room display app. The new version of the Room display might be available to install. Check the App Store or Google Play for updates, or simply click on the `Update` button.
</Accordion>

<Accordion title="4. Your RNTOR subscription is not active">
  [Check your RNTOR subscription](/admin/administration/billing/rntor-subscription) status to make sure it is active and not suspended.
</Accordion>

<Accordion title="5. The device doesn't meet technical requirements">
  Ensure your tablet device meets the [requirements](/admin/resource-management/room-display/set-up-room-display) to install the Room display app.
</Accordion>
