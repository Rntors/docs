---
title: "Overlapping resources"
description: "Link overlapping parent-child resources to automatically synchronize calendar availability and prevent overbooking when a main room or its smaller sections are reserved"
---

Link overlapping resources to automatically manage their availability and eliminate manual calendar cross-checking. This is useful in the following cases:

* Link a large room to its two halves so booking the **Big room** blocks both halves, and vice versa.
* Automatically block individual rooms and desks when the entire space or an event hall is reserved. ​

## Configure parent-child resources

To set up linked resources, first create each option as a separate resource and then define their relationship.

1. Create separate resources for every booking configuration you offer.
2. Determine which room acts as the parent and which rooms or desks are the children.

| Scenario   | Parent resource    | Child resource(s)                 |
| ---------- | ------------------ | --------------------------------- |
| Split room | Full room          | Room half A, Room half B          |
| Full space | Full space booking | Every individual desk/room inside |

<Info>
  Only a room can be designated as a parent resource.
</Info>

3. [Open the settings](/admin/resource-management/resources/set-up-resources) for each **child** resource (e.g., a desk or a half-room).
4. Find the **Parent room** field and select the corresponding larger room from the dropdown menu.

## How linked resources work

Once linked, RNTOR automatically synchronizes availability between the parent and child resources to ensure you never overbook a physical area.

* When the parent room is booked, all of its linked child resources are automatically blocked for that specific date and time slot.

<Frame>
  <img src="" alt="" width="1263" height="906" data-path="images/resource-management-bookings-link-overlapping-resources-2.png" />
</Frame>

* When a child resource is booked, the parent room is automatically blocked. However, "fellow" child resources (other children linked to the same parent) remain available for booking.
* If the main booking is rescheduled or canceled, the associated blocks on the linked resources are updated or removed automatically, keeping your resource availability accurate in real-time.
