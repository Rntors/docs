  <Tab title="Rooms">
    Add your Skype rooms, phone booths, meeting rooms, conference rooms, or event spaces to the **Rooms** page. This gives customers a convenient calendar view to check availability and make bookings.

    ## Enable Rooms

    To start using the **Rooms** module:

    1. In the left-side panel, click the menu **(...)** next to your location name
    2. Go to **Location** **settings** \> **Resources** \> **Rooms** and toggle the **Rooms** switch on.
    3. **Page name** — choose the best fit.
    4. **Book ahead** — set how far in advance users can book rooms.
       <Info>
         The **Book ahead** limit also applies to recurring bookings. Every occurrence in a repeating booking must fall within the book-ahead window — if the series runs past it, the member portal shows the user up to which date they can book, and they have to adjust the **End repeat** setting of their recurring booking. Select **Unlimited** to let users book with no date limit and remove this restriction.
       </Info>
    5. **Book for free** — limit how many free bookings a user can have scheduled at the same time, if you have free rooms.
       - One active
       - Two active
       - Three active
       - Unlimited

    The **Book for free** setting only applies if you have totally free rooms and only to bookings made by non-administrator users. With this setting, users will be able to make the next free bookings once their previous scheduled bookings have passed. [Optimize room usage](/guides/revenue-and-space-optimization/optimize-room-usage)

    ![Resource Management Rooms 1](/images/resource-management-rooms-1.png)

    ## Add rooms

    1. Go to the **Resources** \> **Rooms** page.
    2. Click **Add room** top right.

    ![Resource Management Rooms 2](/images/resource-management-rooms-2.png)

    3. Fill in the room details.

    | **Section name** | **Meaning** |
    | :-- | :-- |
    | **Room photo** | 2x1 format. |
    | **Type** | <ul><li>Room</li><li>Conference room</li><li>Event space</li><li>Meeting room</li><li>Phone booth</li><li>Studio</li></ul> |
    | **Name** | Room name and/or number. |
    | **Seating capacity** | The number of people the room fits. |
    | **Description** | Include any important information customers need to know. |
    | **Money** | The monetary price for hourly/daily bookings in your location currency. [<u>Set up pricing for resources</u>](/admin/resource-management/resources/set-up-pricing) |
    | **Credits** | The credit price for hourly/daily bookings. |
    | **Dynamic pricing (beta)** | Automatically adjusts room booking price based on demand within your defined range. [<u>Set dynamic pricing for resource</u>](/admin/resource-management/resources/dynamic-pricing) |
    | **Plans** | If you offer long-term rentals (weekly, monthly, etc.) of this room, enable the **Plans** switch and add tiers. <ul><li>Disable this switch if the room is only available for hourly/daily bookings.</li></ul> [<u>Set up pricing for resources</u>](/admin/resource-management/resources/set-up-pricing) |
    | **Availability increment** | The frequency of available time for room booking. It shows up as a step on the booking. |
    | **Min & Max duration** | Minimum & maximum duration limits for hourly/daily bookings. Applies to all users except administrators. <ul><li>To offer different limits for nonmembers, enable "**Public duration**," and set the min & max duration that will apply to them.</li></ul> |
    | **Preparationtime** | Buffer time that will be reserved between bookings. |
    | **Reschedulingpolicy** | Select whether users can reschedule bookings for this room or cancel and get automatic refunds. [<u>Understand refunds</u>](/admin/billing/payments/refunds) |
    | **Custom schedule** | Set [<u>custom working hours</u>](/admin/location/schedule#configure-a-custom-schedule-for-a-resource) for this room, independent of the location's overall schedule. |
    | **Confirmation email** | If you want to send a [<u>custom booking confirmation email</u>](/admin/general/customize-emails#booking-confirmations), select which users should receive it when making a booking, and paste your email text. |
    | **Visibility** | Determine which user groups can see this room. |
    | **Booking** | Determine which groups of users can immediately book the room, while others can apply for a booking. <ul><li>[<u>Book a room</u>](/member/bookings/book-a-room)</li><li>[<u>Configure room booking permissions</u>](/admin/resource-management/resources/applications-for-bookings)</li></ul> |
    | **Parent room** | If this room overlaps with or is related to a larger space (e.g., it's half of a split room, or located within an Event hall), select that larger space as a **Parent room**. When the parent room is booked, this room is automatically blocked for booking, and vice versa. |
    | **Abandoned booking protection\*** | Automatically remove ghost bookings from the room's calendar if nobody checks in. Available only with [<u>Room display</u>](/admin/resource-management/room-display/set-up-room-display). _\*This option appears only if the room is totally free of charge._ |
    | **Access** | Determine the access control group to which users are synced upon booking this room. <br />​Appears if you have the [<u>integration with the access control system</u>](/admin/integrations/access-control/set-up-access-control) connected in the location. |

Consider adding links to equipment in room descriptions to inform customers of available options and encourage upsells in addition to bookings.
    </Tip>

    ## Edit a room

    To update the settings of a room, follow these steps:

    1. Navigate to **Resources** \> **Rooms.**
    2. Find the room you need to edit and hover over it \> click the menu **(...)** next to it \> **Edit**.

    ![Resource Management Edit A Resource 1](/images/resource-management-edit-a-resource-1.png)

    3. Adjust the room settings as needed.
    4. Press **Save** in the top right corner.

    <Info>
      Changes to the price in any [price tier](/admin/resource-management/resources/set-up-pricing) and the [rescheduling policy](/admin/billing/payments/refunds) will apply only to future bookings created after the update.
    </Info>

    ## Delete a room

    To permanently delete a room from RNTOR, follow these steps:

    1. Navigate to **Resources** \> **Rooms.**
    2. Find the necessary room and hover over it \> click the menu **(...)** next to it \> select **Delete** and confirm your choice.

    ![Resource Management Delete A Resource 1](/images/resource-management-delete-a-resource-1.png)

    <Warning>
      Deleting a room is irreversible. All associated bookings will be permanently deleted without a refund and cannot be restored. Booking analytics for the deleted room will also no longer be available.
    </Warning>

    **FAQs**

    <Accordion title="What should I add to the Rooms?">
      The **Rooms** page serves for your meeting and conference rooms, phone booths, and Skype rooms. If you have any photo or podcast studios, offer them on the **Rooms** page too. ​
    </Accordion>

    <Accordion title="How can I block off all rooms from bookings for several days?">
      If you are having an event in the space or holidays are coming, mark the corresponding dates as closed in your location schedule so that all resources are unavailable for bookings by your customers on those dates.

      To block only rooms while keeping other resources available, mark the corresponding dates as closed in each room's custom schedule. [Configure the schedule](/admin/location/schedule) ​
    </Accordion>

    <Accordion title="How to define the room booking schedule for members and nonmembers?">
      You can either configure a location-wide schedule that applies to all resources or configure a custom schedule for a specific room if it needs different availability. [Configure the schedule](/admin/location/schedule)
    </Accordion>

    <Accordion title="Why can't a customer see a certain room?">
      The customer might not see a room for the following reasons:

      1. The customer's role may not meet the room's visibility requirements. For example, if the room is visible only to **Location members** but the customer is a nonmember, it won't appear for them. Check both the [room's visibility](/admin/location/visibility) settings and the [customer's role](/admin/customer-management/users/user-roles).
      2. The room may be assigned to a specific customer, making it visible and bookable only for them. On the **Rooms** page, see if a member or company name appears next to the room. To remove the assignment, edit that customer's subscription.
      3. The customer may have logged in with a different email. If they are a member and should see the room, check the email tied to their member profile on the **Customers** page.
    </Accordion>

  <Tab title="Desks">
    Add and manage all workstations—such as hot desks, dedicated desks, or stations—on the **Desks** page.

    With desks, you can:

    - Organize your workstations for a real-time occupancy tracking
    - Offer short-term bookings (hourly or daily) and/or long-term rentals (subscriptions).

    ## Configure general desk settings

    1. In the left-side panel, click **(...)** next to your location name.
    2. Go to **Location** **settings** \> **Resources** \> **Desks.**
    3. Make sure the **Desks** switch is toggled on.
    4. **Page name** — choose the best fit.
    5. **Book ahead** — set how far in advance users can book desks.
    6. **Day passes** — allow members to book hot desks using the [day passes payment method.](/admin/billing/credits-and-day-passes/day-passes)
    7. **Usage limit** — restrict how many day passes members can use per day.

    ![Resource Management Desks Configure General Desk Settings](/images/resource-management-desks-configure-general-desk-settings.png)

    ## Set up desks

    1. Go to **Resources** \> **Desks**.
    2. Click **Add desk** top right.

    ![Resource Management Desks 2](/images/resource-management-desks-2.png)

    - **Desk photo** — 2x1 format.
    - **Type**
      - **Hot desk** — shared, not dedicated to a specific customer, bookable based on availability.
      - **Dedicated desk** — can be reserved for a specific customer.
      - **Station** — workspace, typically equipped with tools or furniture for job.
    - **Name** — choose your naming approach:
      - **Zones** (e.g., **Open Space**, **Lounge Zone**, or **Open space 1 floor** and **Open space 2 floor**) with total seating capacity to track occupancy by zone.
      - **Numbered desks** (e.g., **Dedicated Desk 1**) to let users book/sign up for a specific desk. [Desk setup options](#desk-setup-options)
    - **Seating capacity —** number of seats this desk or zone allows.
    - **Description —** information customers need to know.
    - **Money —** monetary price for hourly/daily bookings.
      - Disable if the desk is only available for long-term rental.
    - **Credits —** credit price for hourly/daily bookings.
      - Disable if the desk is only available for long-term rental.
    - **Day passes** **—** let members book this desk with [day passes payment method.](/admin/billing/credits-and-day-passes/day-passes) _Appears only for **Hot desk** type._
    - **Dynamic pricing —** automatically adjusts booking price based [on demand](/admin/resource-management/resources/dynamic-pricing)_._
    - **Plans —** enable if you offer long-term rentals (weekly, monthly, etc.) of this desk, and [add tiers.](/admin/resource-management/resources/set-up-pricing)
      - Disable if the desk is only available for hourly/daily bookings.
    - **Availability increment —** booking time step.
    - **Min & Max duration —** booking duration limits. Applies to all users except administrators.
    - **Public duration —** enable to set different booking duration limits for nonmembers.
    - **Rescheduling policy —** select whether users can reschedule bookings or cancel and get automatic [refunds](/admin/billing/payments/refunds).
    - **Custom schedule —** [custom working hours](/admin/location/schedule) for this desk.
    - **Confirmation email —** send a [custom booking confirmation email](/admin/general/customize-emails). Select which users should receive it and paste the text.
    - **Visibility —** define which user groups can see this desk.
    - **Booking —** define which user groups can immediately [book the desk](/member/bookings/book-a-desk), while others can [apply for a booking](/admin/resource-management/resources/applications-for-bookings).
    - **Parent room —** if this desk overlaps with or is related to a larger space (for example, located inside an Event hall), select that larger space to [link them.](/admin/resource-management/resources/overlapping-resources)
    - **Access —** the access control group for users who book or rent this desk. _Appears if you have the [integration with the access control system](/admin/integrations/access-control/set-up-access-control)._
    - **Calendar sync —** sync bookings for this desk with [Google Calendar.](/admin/integrations/bookings/google-calendar)

    ### Desk setup options

    **By zones** — if you want users to book desks without choosing a specific seat:

    - Create each zone as a desk
    - Set the seating capacity in each zone
    - Users select the zone and book one or more seats.

    If you use floor plans, desks will be reflected as follows:

    ![Resource Management Desks 3](/images/resource-management-desks-3.png)

    **Individual desks** — if you want users to choose a specific seat:

    - Create each desk as a separate resource
    - Set the seating capacity to 1
    - Users select and book a specific seat they prefer.

    If you have floor plans, desks will be reflected accordingly:

    ![Resource Management Desks 4](/images/resource-management-desks-4.png)

      [Bulk create desks](/admin/noor-ai/bulk-create-resources-products-events-and-benefits) with the help of Noor AI.

    ## What's next

    Once your desks are set up:

    - Customers can discover them on the **Desks** page and [book](/member/bookings/book-a-desk) or [sign up for rental.](/admin/resource-management/resources/rental-applications-or-immediate-sign-ups)
    - Administrators [receive notifications](/admin/administration/your-account/notifications/set-up-notifications) about new bookings and sign-ups on the **Notifications** page.
    - The **Desks** page shows a real-time overview of desk occupancy across your space.

    ![Resource Management Desks 5](/images/resource-management-desks-5.png)

    - Additionally:
      - Track bookings by day on **Desks** \> **Bookings** tab.
      - View all bookings by period or customer on **Resources \> Bookings**.
      - Track all long-term desk rentals on **Resources** \> [**Assignments**](/admin/analytics-reports/track-occupancy) [timeline.](/admin/analytics-reports/track-occupancy)

    ## Edit equipment

    To update the settings of equipment, follow these steps:

    1. Navigate to **Resources** \> **Equipment.**
    2. Find the equipment you need to edit and hover over it \> click the menu **(...)** next to it \> **Edit**.
    3. Adjust the equipment settings as needed.
    4. Press **Save** in the top right corner.

    <Info>
      Changes to the price in any [price tier](/admin/resource-management/resources/set-up-pricing) and the [rescheduling policy](/admin/billing/payments/refunds) will apply only to future bookings created after the update.
    </Info>

    ## Delete equipment

    To permanently delete equipment from RNTOR, follow these steps:

    1. Navigate to **Resources** \> **Equipment.**
    2. Find the necessary equipment and hover over it \> click the menu **(...)** next to it \> select **Delete** and confirm your choice.

    <Warning>
      Deleting equipment is irreversible. All associated bookings will be permanently deleted without a refund and cannot be restored. Booking analytics for the deleted equipment will also no longer be available.
    </Warning>
