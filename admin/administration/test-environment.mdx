A test environment is an isolated network for trying settings and building integrations without changing your live data.

<a id="set-up-test-environment" />

## Create a test environment

Only an [owner](/admin/administration/administrators/administrators) can create or delete test environments.

1. Open **Settings** > **Developers** for your network.
2. Select **Test environments** > **Create test environment**.
3. Enter the name, timezone, and currency, then select **Create**.
4. Confirm the charge and select **Open test environment**.

You can create several test environments. Each is a paid add-on; see [pricing](https://rntor.com/en/pricing).

## How test environment works

The test network provides the same core workflows, with these exceptions:

- Use [Stripe](/admin/integrations/payments/stripe/stripe) in Test mode for payment testing.
- Connect [Google Calendar](/admin/integrations/bookings/google-calendar) to synchronize bookings in your test network.
- Connect [QuickBooks Online](/admin/integrations/accounting/quickbooks-online) to a **Sandbox** company. Test networks use QuickBooks Sandbox; live networks use production companies.
- Custom domains are unavailable.
- Email subjects and invoice, receipt, and credit note PDFs carry a `[TEST]` label. These are test documents, not fiscal documents.
- [eSignatures](/admin/billing/contracts/esignature) use the provider's test environment. Test contracts are marked as non-binding. RNTOR uses BoldSign for electronic signatures.
- Live add-ons do not transfer: Visitors, Floor plans, Member mobile app, and Custom MAIL FROM are unavailable. API access is included.
- You can add any number of [locations](/admin/administration/locations).

## Delete a test environment

1. As an owner, open **Settings** > **Developers** > **Test environments**.
2. Open the environment's **(...)** menu and select **Delete**.
3. Confirm deletion.

Its charge stops at the next subscription renewal.

<Warning>
  Deletion permanently removes the test environment and its data. It cannot be undone.
</Warning>

## Access to API in test environment

[API credentials](/admin/administration/api-and-webhooks) are included at no additional cost and work only against the test network.

To use an integration with live data, the owner [purchases the API & webhooks add-on](/admin/administration/billing/make-changes-to-rntor-subscription#upgrade-subscription) for the live network. [Delete the test environment](#delete-a-test-environment) when you no longer need it.

## Switching environments

Open the network selector in the admin portal and choose the live or test network you want to work in.
