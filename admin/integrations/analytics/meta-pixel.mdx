Maximize the efficiency of your ad campaigns by connecting Meta Pixel to RNTOR and tracking all user events.

Meta Pixel supports tracking of user behavior in the member web portal through the following events.

| **Event name** | **Explanation** |
| --- | --- |
| PageView | A user viewed a page |
| InitiateCheckout | A user initiated a payment |
| Purchase | A user successfully made a monetary purchase. |
| Schedule | A user schedules a tour booking on the member web portal landing page via the [integration with Calendly](/admin/integrations/bookings/calendly). |
| AddToCart | A user added shop products to cart. |

<Info>
  Integration with Meta Pixel is only available for tracking events in your member web portal.
</Info>

## Prerequisites

To enable Meta Pixel integration with RNTOR, make sure you've completed the following prerequisites:

1. Have an active RNTOR subscription.
2. Have your Meta Pixel account set up.

## Connect the Meta Pixel integration

1. The [owner](/admin/administration/administrators/owner) needs to go to RNTOR \> **Network settings** page by pressing the network name \> **Integrations** \> **Meta Pixel.** ​

![Image](/images/integrations/analytics-meta-pixel-1.png)

2. Insert your Meta Pixel ID and press **Connect**.

Once the integration is connected, you can instantly export users into Meta audiences and track events in the member web portal. Include links to various pages of your member web portal in your ads. The links might lead to such pages as:

- Rooms
- Desks
- Plan sign-ups
- [Member web portal landing page](/admin/general/member-web-portal/customize-landing-page)

<Tip>
  Learn how to get URLs to specific pages in the member web portal and [how to promote them](/guides/promotion/integrate-with-your-marketing-website#buttons-for-specific-services).
</Tip>

Continuously track user purchases in the member web portal and monitor conversions from ad campaigns with these links to optimize your ads.

## Disconnect the Meta Pixel integration

To disconnect Meta Pixel, follow these steps:

1. Go to RNTOR as an [owner](/admin/administration/administrators/owner) \> **Network settings** page by pressing the network name \> **Integrations** \> **Meta Pixel.**
2. Press **Disconnect** and confirm your choice.
