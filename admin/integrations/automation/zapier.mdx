## How Zapier works

Triggers and actions are events inside your apps. A Zap connects a trigger in one app with an action in another, letting Zapier take care of tasks automatically when a trigger event occurs.

RNTOR offers triggers and actions you can use with Zapier to link with other apps. Learn more on [Zapier’s page](https://rntor.com/integrations).

![Image](/images/integrations/automation-zapier-1.png)

### Supported triggers

A trigger is an event that starts an automated workflow.

| Trigger name | Description |
| --- | --- |
| Booking Ends | Triggers when a booking ends in a resource. |
| Member Deleted | Triggers when a member is deleted from a location. |
| New Benefit Application | Triggers when a new benefit application is made in a location. |
| New Booking | Triggers when a new booking is made in a resource. |
| New Company | Triggers when a new company is created in a location. |
| New Event Ticket | Triggers when a new event ticket is purchased in a location. |
| New Issued Invoice | Triggers when a new invoice is issued in a location. |
| New Member | Triggers when a new member is invited to join a location. |
| New Network Registration | Triggers when a new user registers in a network. |
| New Order | Triggers when a new order is made in a location. |
| New Request to Join | Triggers when a new request to join is made in a location. |
| New Subscription | Triggers when a new subscription is created in a location. |
| New Support Ticket | Triggers when a new support ticket is created in a location. |
| New Visit | Triggers when a new visit is created in a location. |
| Subscription Ended | Triggers when a subscription is ended in a location. |
| Subscription Expiring | Triggers when a subscription is expiring in a location. |
| Subscription Purchased | Triggers when a subscription is purchased in a location. |

#### Supported actions

An action is the task that Zapier performs in response to the trigger.

| Action name | Description |
| --- | --- |
| Create Booking | Creates a new booking in a resource. |
| Create Company | Creates a new company in a location. |
| Create Feed Post | Publishes a new post. |
| Create Subscription for Company | Creates a subscription for a company. |
| Create Subscription for User | Creates a subscription for a user. |
| Create Visit | Creates a new visit in a location. |
| Delete Booking | Deletes a booking in a resource. |
| Delete Member | Deletes a member by ID. |
| Invite Member | Invites a new member to a location. |
| Update Subscription | Changes the subscription's end date. |

#### Supported searches

A search is used to look up specific data in an app before performing an action.

| Search name | Description |
| --- | --- |
| Find Company | Finds a company in a location by title or ID. Optionally, creates a company if none are found. |
| Find Member | Finds a member in a location by title or ID. Optionally, creates a member if none are found. |
| Find Booking | Finds a booking. Optionally, creates a booking if none are found. |

## How to set up an automation

To connect RNTOR with another app, follow these steps:

1. Log in to [Zapier](https://zapier.com/app/login) and start [creating a Zap](https://help.zapier.com/hc/en-us/articles/22234847450893-Zap-workflows-quick-start-guide).
2. When choosing RNTOR as a trigger or action, connect your account by signing in using your RNTOR [administrator](/admin/administration/administrators/administrators) email address.
3. Configure the necessary automation by selecting relevant triggers and actions.
4. Test and publish your Zap.

### Common cases

Zapier integration with RNTOR allows you to connect a wide range of apps. Some of the most popular scenarios include:

- **CRM integration** Automatically invite contacts to your member portal and mobile app, or create new CRM entries when members are added in RNTOR. [HubSpot example](https://zapier.com/apps/hubspot/integrations)
- **Accounting integration** Sync invoices and monetary payments for services, and keep customer records in sync across systems.

<Tip>
  Explore [more ways](/admin/billing/invoices/accounting) to connect RNTOR with your accounting tools.
</Tip>

- **Notifications and external communications** Notify benefit or product providers, track user registrations through automated notifications with Gmail, Outlook, Slack, and more. Use Gmail for automation [Gmail example](https://zapier.com/apps/gmail/integrations)
