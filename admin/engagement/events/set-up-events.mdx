Post your community events on the **Events** page and let customers easily discover them and join or buy tickets.

## Create an event

1. Go to the **Location settings** > **Engagement >** **Events** tab, and enable the **Events** switch.
2. Go to **Engagement** > **Events** and press **Create event** top right.

| Cover photo        | An image in 2×1 ratio.                                                                                                                                                                                    |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Name               | The name of the event.                                                                                                                                                                                    |
| Venue              | The address where your event takes place.                                                                                                                                                                 |
| Starts             | Event start date and time.                                                                                                                                                                                |
| Ends               | Event end date and time.                                                                                                                                                                                  |
| Description        | Details about your event.                                                                                                                                                                                 |
| Limited attendees  | Enable to limit the number of attendees.                                                                                                                                                                  |
| Show attendees     | Enable to show the number and list of attendees under the event.                                                                                                                                          |
| Joining            | If enabled, your customers will be able to join the event - purchase a ticket if the event is paid or book a spot if the event is free. Customers can purchase one or multiple tickets in a single order. |
| Pricing            | Indicate ticket prices in ☆ and money. To create a free event, leave both **Money** and **Credits** options disabled.                                                                                     |
| Custom tax rate    | Enable to set [custom tax rate](/admin/billing/taxes/custom-tax-rates) for the event monetary price if the fixed location tax doesn't apply to it.                                                              |
| Refund policy      | Select whether tickets are refundable. If canceled before the set time, an [automatic refund](/admin/billing/payments/refunds) will be issued.                                                                  |
| Confirmation email | Enable this to send event attendees a [custom confirmation email](/admin/general/customize-emails).                                                                                                             |
| Visibility         | Manage access to the event by making it visible to administrators, location members, network members, or the public.                                                                                      |

3. Press the **Create** button.
4. Upon saving an event, press the **Add** button to add hosts. This will allow users to know who will be running the event.

![Create an event on RNTOR coworking space management platform](/images/engagement-events-1.png)

<Info>
  Hosts can be selected from location members.
</Info>

## Create recurring events

If your event only repeats once or a few times, you can duplicate it directly:

1. On the **Events** page, click **(...)** next to the event > **Duplicate**.
   ![Engagement Events Create Recurring Events](/images/engagement-events-4.png)
2. The duplicated event will open.
3. [<u>Edit it</u>](#edit-an-event) and update details such as date, time, or any other information.

<Tip>
  [Create multiple recurring events](/admin/noor-ai/bulk-create-resources-products-events-and-benefits) with Noor AI.
</Tip>

## Check in event attendees

Administrators can check in event attendees to keep track of who's arrived. RNTOR offers two convenient methods for you to do this.

### Check in by scanning attendee tickets

1. On your mobile device, log in to RNTOR in your browser or PWA (Progressive Web App).
2. Ask the event attendee to open their event ticket from the **Account > Tickets** page on their device.
3. Scan the **QR code** on the attendee's ticket using your phone's camera.
4. Tap **Check in**.

![Events image 5](/images/engagement-events-check-in-event-attendees-1.png)

### Check in directly from your RNTOR account

1. Log in to RNTOR on your mobile device or desktop.
2. Go to **Engagement > Events** page > open the event and tap on the necessary attendee.
3. Tap **Check in** at the bottom of the page.

![Events image 6](/images/engagement-events-check-in-event-attendees-2.png)

Checked-in event attendees have a green checkbox next to their name on the attendee's list.

![Events image 7](/images/engagement-events-check-in-event-attendees-3.png)

### Export event attendees

* After your event concludes, enhance your understanding of its efficiency by downloading the event attendees CSV: 1. Go to **Engagement** > **Events** > open the relevant event. 2. Click **(...)** on the top right corner > Export attendees as CSV.

![Events image 8](/images/engagement-events-check-in-event-attendees-4.png)

* This CSV provides the attendees contacts, create date, check in date, ticket quantity, and payment details.
* This segmentation enables you to tailor your outreach strategies: for example, you can send a personalized thank-you and share event highlights with attendees. This helps improve future event planning and conversions.

## Edit an event

Editing an event allows you to make changes or updates to the event details, such as the date, time, or any other information.

1. Go to the **Engagement** > **Events** page.
2. Hover over the event > press the menu **(...)** next to it > press **Edit**.

![Events image 9](/images/engagement-events-1.png)

3. Make the necessary changes and press **Save**.

## Cancel the event

1. Go to the **Engagement** > **Events** page.
2. Click the **(...)** menu button next to the necessary event > **Cancel**.

![Events image 10](/images/engagement-events-cancel-an-event-1.png)

### How users are notified about event cancellation

All event attendees receive a push and an email [notifications ](/member/account/notifications)that the event has been canceled.

## Delete an event

1. Go to the **Engagement** > **Events** page.
2. Hover over the event > press the menu **(...)** next to it > press **Delete** and confirm your choice.

<Warning>
  Deleting an event is irreversible and can not be undone.
</Warning>

**FAQs**

<Accordion title="How to make events free for members, and paid for nonmembers?">
  To give members free access to all or a specific event, [add a 100% discount coupon](/admin/billing/discounts/apply-discounts-to-bookings-and-purchases) for event tickets in their subscription. Then, when creating an event, set the regular price for nonmembers.
</Accordion>

<Accordion title="Can members add events to the app?">
  Only administrators can create events. However, you can allow members to submit event requests through the **Shop** page.

  To set this up, [create a product](/admin/service/shop/set-up-shop) on the **Shop** page (e.g. **Request to host an event**) with relevant rules, a questionnaire, and your event hosting guidelines. Interested members can apply by purchasing the product and providing event details in the **Comment** section. An administrator will then review the request, create the event, and select the member as a host.
</Accordion>

<Accordion title="Why can't I see the Promote button?">
  To be able to promote your event, make sure that:

  * The event has not reached its attendee limit (based on the **Limited attendees** setting).
  * The event has not been canceled.
  * The [**Feed**](/admin/engagement/feed) [page is enabled](/admin/engagement/feed) in your location.
</Accordion>

<Accordion title="Why is the 'Promote' event feature generating posts in the wrong language?">
  The **Promote** event feature relies on AI to identify the language and context of your event. If your title or description is too generic (e.g., "test event"), the system may misinterpret it. For best results, add a clear and descriptive title and description so the AI can generate accurate content.
</Accordion>
