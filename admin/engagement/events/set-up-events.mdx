Post community events on the **Events** page and let customers easily discover them, join free events, or purchase tickets.

## Create an event

1. Go to **Location settings > Engagement > Events** and turn on the **Events** switch.
2. Go to **Engagement > Events** and click **Create event** in the top-right corner.

| Field | Description |
| --- | --- |
| **Cover photo** | An image in a 2:1 ratio. |
| **Name** | The event name. |
| **Venue** | The address where the event takes place. |
| **Starts** | Event start date and time. |
| **Ends** | Event end date and time. |
| **Description** | Details about the event. |
| **Limited attendees** | Enable to limit the number of attendees. |
| **Show attendees** | Enable to show the number and list of attendees below the event. |
| **Joining** | Enable to let customers purchase a ticket for a paid event or book a place at a free event. |
| **Pricing** | Set ticket prices in credits and money. For a free event, leave both options disabled. |
| **Custom tax rate** | Enable to apply a [custom tax rate](/admin/billing/taxes/custom-tax-rates) to the monetary ticket price when the location tax does not apply. |
| **Refund policy** | Choose whether tickets are refundable. If canceled within the allowed period, an [automatic refund](/admin/billing/payments/refunds) is issued. |
| **Confirmation email** | Enable to send attendees a [custom confirmation email](/admin/general/customize-emails). |
| **Visibility** | Make the event visible to administrators, location members, network members, or the public. |

3. Click **Create**.
4. After saving, click **Add** to add hosts so users know who is running the event.

![Create and configure an event in RNTOR](/images/engagement-events-1.png)

Hosts can be selected from location members.

## Create recurring events

If an event repeats only once or a few times, duplicate it:

1. On **Events**, click **(…) > Duplicate** next to the event.

![Duplicate an event in RNTOR](/images/engagement-events-2.png)

2. Open the duplicated event.
3. Update its date, time, and other details.

You can also [create multiple recurring events with Noor AI](/admin/noor-ai/bulk-create-resources-products-events-and-benefits).

## What's next

- Once created, the event appears on **Events**. Review [how users view and join events](/member/events).
- Use **Promote** to create a Feed post about the event and attract more attention.

![Promote an RNTOR event through the Feed](/images/engagement-events-3.png)

- Use the **Calendar** tab for a monthly calendar view, or use **Search** to find an event.

![View events in the RNTOR monthly calendar](/images/engagement-events-4.png)

## Check in event attendees

Administrators can check in event attendees to keep track of who has arrived. RNTOR offers two convenient methods for you to do this.

### Check in by scanning attendee tickets

1. On your mobile device, log in to RNTOR in your browser or PWA.
2. Ask the attendee to open their ticket from **Account > Tickets**.
3. Scan the ticket QR code with your phone camera.
4. Tap **Check in**.

![Scan an event attendee ticket and check them in](/images/engagement-events-5.png)

### Check in directly from your RNTOR account

1. Log in to RNTOR on mobile or desktop.
2. Go to **Engagement > Events**, open the event, and select the attendee.
3. Tap **Check in**.

![Check in an attendee directly from an RNTOR event](/images/engagement-events-6.png)

Checked-in attendees have a green checkbox next to their name.

![Checked-in event attendee indicator in RNTOR](/images/engagement-events-7.png)

### Export event attendees

1. After the event, go to **Engagement > Events** and open it.
2. Click **(…) > Export attendees as CSV**.

![Export event attendees as CSV from RNTOR](/images/engagement-events-8.png)

The CSV includes attendee contacts, creation date, check-in date, and payment details. Use this information to tailor follow-ups, such as sending thank-you messages and event highlights.

## Edit an event

1. Go to **Engagement > Events**.
2. Hover over the event and select **(…) > Edit**.

![Edit an event in RNTOR](/images/engagement-events-9.png)

3. Make the changes and click **Save**.

## Cancel an event

1. Go to **Engagement > Events**.
2. Select **(…) > Cancel** next to the event.

![Cancel an event in RNTOR](/images/engagement-events-10.png)

### How users are notified about event cancellation

All attendees receive push and email [notifications](/admin/administration/your-account/notifications/set-up-notifications) that the event was canceled.

![Event cancellation notification in RNTOR](/images/engagement-events-11.png)

Users also see a red **Canceled** label on the Events page.

![Canceled event label in the RNTOR member portal](/images/engagement-events-12.png)

Attendees do not receive a refund merely because an administrator cancels the event. Review how to [issue refunds](/admin/billing/payments/refunds).

## Delete an event

1. Go to **Engagement > Events**.
2. Hover over the event, select **(…) > Delete**, and confirm.

<Warning>
  Deleting an event is irreversible and cannot be undone.
</Warning>

  <Accordion title="How can I make events free for members and paid for nonmembers?">
    Add a [100% discount coupon](/admin/billing/discounts/coupons-and-promo-codes) for event tickets to member subscriptions, then set the regular ticket price for nonmembers.
  </Accordion>
  <Accordion title="Can members add events?">
    Only administrators can create events. You can let members submit requests through Shop by [creating a product](/admin/service/shop/set-up-shop), such as **Request to host an event**, with the relevant rules and questionnaire. An administrator can then review the request, create the event, and select the member as a host.
  </Accordion>
  <Accordion title="Why can't I see the Promote button?">
    Make sure the event has not reached its attendee limit, has not been canceled, and the [Feed page](/admin/engagement/feed) is enabled.
  </Accordion>
  <Accordion title="Why is Promote generating a post in the wrong language?">
    Promote uses AI to identify the event language and context. Generic titles or descriptions can be misinterpreted. Use a clear, descriptive title and description to help generate accurate content.
  </Accordion>
</AccordionGroup>
