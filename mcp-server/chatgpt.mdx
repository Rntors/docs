## Install RNTOR in ChatGPT

<Steps>
  <Step title="Open Plugins">
    In ChatGPT, open **Settings → Plugins**. If RNTOR is visible in the directory, open its listing and choose **Install plugin**.
  </Step>
  <Step title="Connect RNTOR">
    Choose **Connect** when ChatGPT prompts you to authorize the plugin.
  </Step>
  <Step title="Sign in">
    Sign in with an active RNTOR account. Reviewers can use the password option shown only during a valid OAuth consent flow.
  </Step>
  <Step title="Select a network">
    Choose the network ChatGPT may access. This selection is mandatory and cannot exceed your RNTOR permissions.
  </Step>
  <Step title="Allow read-only access">
    Review the data categories and choose **Allow**. ChatGPT returns to the conversation once OAuth completes.
  </Step>
</Steps>

## Connect as a custom MCP server

If the public plugin listing is not visible in your ChatGPT workspace, use the custom connector flow available to your plan:

1. Open the ChatGPT connector or plugin settings and choose to add a custom MCP server.
2. Enter **RNTOR** as the name.
3. Use the canonical URL:

```text
https://mcp.rntor.com/mcp
```

4. Connect, sign in, select a network, and allow access.

<Warning>
  Do not use the Supabase function URL for new connections. The supported public endpoint is `https://mcp.rntor.com/mcp`.
</Warning>

## What ChatGPT can access

ChatGPT can use the same [35 read-only RNTOR tools](/mcp-server#supported-tools) documented for every MCP client.

The connection can retrieve only:

- the network selected during OAuth;
- records allowed by the signed-in user’s RNTOR role;
- the requested live or test environment, never both;
- non-internal locations; and
- minimized fields defined by each tool’s structured output schema.

It cannot modify records, process payments, sign contracts, expose private storage paths, or trigger workflows.

## Use RNTOR in a conversation

Mention RNTOR or select the plugin when starting a question. ChatGPT may call several tools to answer one request.

For best results:

- identify the location, customer, resource, or date range when you know it;
- ask for a table when comparing records;
- use ranges of 366 days or less;
- continue in the same conversation when refining an answer; and
- ask ChatGPT to reduce parallel calls if it encounters a temporary rate limit.

## Disconnect or switch networks

Open ChatGPT **Settings → Plugins** (or your connector settings), find RNTOR, and disconnect it.

To switch the authorized network, reconnect and select another eligible network on the RNTOR consent screen.

## Troubleshooting

### The sign-in page does not return to ChatGPT

Start a fresh connection from ChatGPT. OAuth authorization links expire and should not be bookmarked or reused.

### My credentials are rejected

Confirm that the account is active and eligible for the selected network. The password option is available only when the login page was opened from a validated OAuth consent flow.

### ChatGPT cannot find a record

Confirm the record belongs to the selected network and environment. Internal locations and cross-network records are intentionally inaccessible.

### I authorized the wrong network

Disconnect RNTOR and reconnect it. Select the intended network before choosing **Allow**.

### I need support

Contact [support@rntor.com](mailto:support@rntor.com). Never include access tokens, authorization codes, or passwords in a support message.
